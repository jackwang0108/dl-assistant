## §4 失败解读表

> **在实验开始前确定解读方式**。一次实现未观察到预期效应，结论只适用于这次实现。每条写明具体实验和信号、该信号支持的解释、可能的原因类别，以及建议的后续操作。
> **每条必须带「判据三问」，光写结论不讲推导 = 用户在确认点没法审**：
> ① **验什么**——裁决哪个假设、机制链是什么（假设不成立 → 为什么这个量会呈现这个信号）；
> ② **阈值来历**——数字怎么定的（noise_floor 的几倍 / 论文消融幅度 / 量级估算 / 文献先例），允许粗；**没有先验时允许只写方向性预期（如「曲线应上升」「门控值不应饱和」），但必须显式标注「无先验」**；
> ③ **命中意味着什么**——支持哪种解释、可能的原因属于哪一类（执行 / 设计选择 / 机制前提）、下一步建议（修正执行后复验 / 重新选择实现位置并设计方案 / 交 iterate 分析原因）。**观察到表中的信号只触发相应分析，不能据此直接判定论点已被证伪。**
