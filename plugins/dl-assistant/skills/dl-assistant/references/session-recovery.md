# 恢复研究与执行上下文

会话恢复时核对当前项目根、版本、代码与实际任务，先读 `PROJECT_CONTEXT.md`、当前spec/plan、claims、上一轮结论和台账中未完成项。文件可能过期，与代码/数据版本不一致时先查证，不能仅凭已存在就继续。

给用户简短说明：

1. 当前定义的研究问题与假设，原来有什么依据；文献与本项目数据分开。
2. 当前执行状态、数据有效性与命题证据，哪些仍未知，不把supported数量称为创新点数。
3. 实际代码/配置版本和相关模块，必要时看diff、原数据及测量/统计代码；不能只读旧笔记。
4. 本轮获批目标、未完成任务、剩余预算与下一步；已有授权保留，实质变化再确认。

PROJECT_CONTEXT只保存稳定背景与报告索引，不复制所有证据；需要时读取具体docs/版本实验记录。资料与源码可自行按需读取；需要派子agent时按对应skill的派前确认要求执行，不强制每次恢复都派遣。

已有任务先结合进程、退出码、日志和实际产物核实，完成记录不一致时恢复缺失信息，不能重复启动同一长任务或用缺退出码推断仍在运行。
