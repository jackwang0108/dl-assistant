# 主要论点与证据分析

把论文拆成可明确陈述的主要论点，为每项记录依据及适用范围。可以公开解释分析结果，不使用读者难理解的内部分类名称。

## 论点与关系

识别作者声称的方法、发现、定理、规律、数据资源或评测能力，区分主要结论与补充细节。按理解所需组织阅读，不要求所有贡献相互依赖。

对于作者声称的依赖关系，明确前一项如何支持后一项：观察是否支持设计动机、定理假设是否符合应用、实验是否检验声称的机制。并列贡献可以分别成立；不相关的两项贡献本身不构成缺陷。类比、动机、相关性与逻辑推导不能混同。

## 主要论点与证据对应表

每个关键论点给局部编号，编号只在本笔记使用，不等于中期研究项目的 `claims.json`。记录：

| 列 | 要求 |
| --- | --- |
| 论点 | 作者具体声称什么，必要时保留量词与适用条件 |
| 原文位置 | 论文版本、节、公式、图表或 PDF 页码；源码与 PDF 定位不同时说明 |
| 依据 | 证明、对照实验、测量、案例或作者解释，附实际读取位置 |
| 设置与条件 | 模型、数据、对照、指标、假设、成本和误差范围中相关的部分 |
| 判断 | 有支持证据、证据不足、存在相反证据、尚未核实 |
| 未决问题 | 尚未排除的解释、未读部分、进一步核查动作 |

一次实验支持什么要按实际条件表述，不从未观察到效应直接否定所有实现，也不从相关性直接推断因果。多个论点可以共用证据，但逐项解释对应关系。

## 不同内容的讲解与检查

| 内容 | 讲清什么 | 检查重点 |
| --- | --- | --- |
| 方法 | 模块作用、输入输出、设计理由、关键公式与计算流程 | 对照是否相关、公平条件、机制证据、误差、计算成本与适用范围 |
| 分析发现 | 问题、测量方式、观察结果与替代解释 | 混杂变量、样本选择、测量有效性、因果解释和外推限制 |
| 定理 | 记号、精确定义、量词与假设、命题、关键证明步骤 | 条件是否完整、推导是否成立、常数和渐近范围、应用是否满足假设 |
| 实证规律 | 扫描变量、控制条件、拟合、具体数值点 | 同时变化的变量、方差、样本范围、拟合区间与外推验证 |
| 数据集或评测 | 构建方法、任务定义、标注与指标含义 | 覆盖性、许可、污染/泄漏、指标有效性及方法偏向 |
| 系统 | 组件职责、接口、资源条件与端到端流程 | 性能与成本、故障边界、对照条件、可复现条件 |

表中是可选检查重点，不强求每篇具备全部实验。对照较老、数据集少或代码未发布只是待分析事实，不直接证明质量差。批评只写有依据的问题，不推测作者是否故意回避。

## 研究线索

组件可以改动不等于替换后有效；每个可替换组件注明作用、当前实现、可能的变更及待验证假设。发现和定理也可产生研究线索，不强行填组件字段。已存在的内容与建议改动分别记录。

`paper_type` 描述内容类型与讲解重点；`core_contribution` 写作者贡献及核实限制。证据评价进 `claim_evidence`，已有工作差异进 `novelty`，研究建议进 `connections`。字段定义统一见 `paper-card.md`，不随论文类型改变字段含义。
