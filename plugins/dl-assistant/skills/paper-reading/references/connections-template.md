# connections.md：后续研究建议

仅在用户讨论过研究延伸时生成。建议来自实际读到的局限、未决问题、组件作用或可能迁移的测量/方法；可以为零项，不为了凑数提出替换方案。阅读理解不以找到研究课题为完成条件。

每项建议包含：

1. **准备验证什么**：具体问题或改动，属于同方向继续研究还是迁移应用。
2. **依据**：本篇实际版本和章节/图表位置；涉及外部方法时给已核实标题与 arXiv ID、DOI 或 URL。
3. **为什么可能有效**：推理和所依赖前提，明确仍是待验证假设。
4. **主要风险与下一步**：可能失败的原因，以及应先查文献还是做何种验证。这里给验证方向，不自动设计完整实验或启动执行。

建议通常 0–3 项。没有可支持的建议时可以说明论文对用户的学习、背景、证据或基准价值，不把想不到延伸解释为论文没有价值。

```markdown
# {论文标题} 后续研究建议

> 稳定论文标识、实际版本、阅读范围与记录日期。

## 1. {具体问题}
- 准备验证什么：
- 本篇与外部依据：
- 为什么可能有效及前提：
- 主要风险与下一步：
- 核查状态：待验证，尚未确认创新性与可行性。

## 后续选项
按用户需要使用 idea-find、baseline-survey 或 literature-survey。
复现之前核对代码选型与环境准备，按对应 skill 的前置要求执行。
```

外部检索用实际可用的论文工具并核对来源；查不到就记待验证，不编造文献，也不强迫每条建议必须有 arXiv 来源。同步更新 card 的 connections，一项建议对应一个条目，分类字段兼容下游，解释使用具体语言。
