# 论文获取、版本与原文定位

## 先核对身份

用户给标题时查标题、作者和来源，多个候选时请用户确认；不能直接选择最相似标题。用户指定版本时保留版本，不静默换最新稿。支持 arXiv ID、DOI、官方 URL 与本地 PDF；本地文件无法确认身份时记录路径及未知字段，不编造 DOI 或 arXiv ID。

正文来源、获取时间、实际版本及可用稳定链接进 card。同一论文源码、PDF、网页或附录不一致时核对版本和内容，不无说明混用。重新开始前先检查已有记录和源版本，需要时再获取新材料。

## 获取方式

- arXiv：优先使用 `tex-mcp` v2 的 tex_open 固定实际版本与入口，再 tex_outline/tex_read。读取一节时检查其直接引用的图表、公式及文献是否取得，跟随 next_cursor 直到结束；未知宏、缺图或引用缺失不可当成已完整理解。原始证据用 tex_read_file，最终排版需要时回 PDF 核查；需要检索身份时使用 `paper-search` v2 的 resolve_papers/get_papers，保留稳定标识与已核版本；下载用 download_paper_asset 返回的 path，文件格式通过不等于内容身份已经核实。具体参数、返回错误与路径按各工具当前接口核实，不假定固定章节编号或调用签名。
- 源码不可用：取得可访问的 PDF，先用 `pdf-mcp` 查看元信息、目录与页数，再按需要分段读取。
- 用户给本地 PDF 或 PDF URL：直接检查和读取，失败时说明原因，不要求一定先转成 arXiv。
- PDF 文字层不可用：可以渲染整页并用可用视觉/OCR 能力读取；区分无法读取和内容不存在。网页正文可用时核实身份与版本后采用。
- 全文都不可用：只基于摘要或已给片段回答，明确不能确认方法细节、完整实验或证明；保存失败与待办，不伪装为完成深读。

自行下载的 PDF 先保存临时文件，检查 HTTP 状态、非空、可解析且确有页面，再作为有效文件使用；HTTP 200 也可能返回错误页面。工具缺失不能声称校验通过。

## 读取与来源位置

先读摘要、引言及实际结论，形成暂定概览。通过目录、章节标题或搜索定位结论，不能假定最后两页就是结论，也不能假定第 1 节包含摘要。

按问题分段读取方法、证据、证明与附录，逐步完成所需范围；大文件不一次全部加入上下文，但这不妨碍完成核心论证的全部核查。图表不能替代必要正文，正文也不能替代查看复杂图表。

图表先核对正文、表头、单位、图例与说明。文字或 LaTeX 表格可清楚读取时优先准确提取；复杂排版再渲染整页或含说明的区域。只抽取嵌入位图可能遗漏矢量图和图注，不据此断言论文没有图。

记录节/公式/图表标识；PDF 同时注明文件页码与印刷页码的差别。每项判断引用实际读到的来源，不凭推测填编号。教学自造例子与论文数字明确分开。

## 继续阅读

先读 card 的版本、覆盖范围、阅读进度、未决问题及相关笔记，再回查支撑当前问题的原文。旧笔记没有某细节不代表原文没有。出现新版、引用冲突或旧解释错误时重新核实，保留修订记录；不重复已确认且与当前版本一致的无关内容。

PDF/结构化全文使用 pdf-mcp v2：pdf_open 固定内容，再以 document_id 读取；同版本 HTML/JATS 可直接利用结构。普通 PDF 文字层顺序未核实，复杂布局只对所需页调用 pdf_parse，并保留 parse_id。OCR/公式识别不默认开启；关键公式与数字核原页，识别输出不是作者源码。
