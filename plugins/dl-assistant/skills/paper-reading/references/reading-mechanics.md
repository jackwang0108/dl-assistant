# 获取论文并按需阅读

本文件说明怎样确认是这篇论文、怎样读到能支撑讲解的原文、缺材料时怎样处理。它展开 [运行步骤](workflow.md) 的 Step 1，也供后续讲解核查原文时使用。根据手头材料执行下列工具调用，拿到结果后再作相应判断。

## 一、确认论文身份，选择入口

- [paper-search](../../paper-search/SKILL.md) 负责检索论文、核对书目信息和版本、查找并下载可用的全文文件。
- [tex-mcp](../../tex-mcp/SKILL.md) 负责读取指定版本的 arXiv TeX 源码，定位章节、公式、图表和引用。
- [pdf-mcp](../../pdf-mcp/SKILL.md) 负责读取 PDF 或同版本的 HTML、JATS XML 全文，并渲染 PDF 原页核对版面和图表。

| 用户提供的材料 | 立即执行的操作 | 核对什么 |
| --- | --- | --- |
| arXiv ID 或摘要页 URL | 用 `tex_capabilities` 确认可用接口，再把 ID 或 URL 交给 `tex_open`。缺书目信息时用 `get_papers` 补查。 | 核对标题、作者和实际版本。保留用户指定的版本。 |
| 标题或不完整的书目信息 | 用 `get_capabilities` 确认可用检索来源，再用 `resolve_papers` 查询候选，例如 `resolve_papers(inputs=[{"title": "论文标题"}])`。 | 比较标题、作者、年份和来源。多个候选都合理时，请用户确认。确认后用取得的稳定标识进入相应读取流程。 |
| DOI 或已知来源标识 | 通过 `get_papers` 查书目信息和已观察版本。只有来源链接且身份不清楚时，可先用 `resolve_papers`。 | 核对来源是预印本、出版版还是其他修订版，再选正文。 |
| 本地 PDF、PDF URL 或身份明确的官方全文 URL | 通过 `pdf_capabilities` 确认可用接口，再用 `pdf_open(source=...)` 打开；以 `pdf_info` 和正文首页核对。 | 核对论文身份和版本。无法确认时记录来源或路径、实际所见内容和未知项。 |
| 只有摘要或摘录 | 先核对材料是否有可识别的标题、作者或 ID。有标识且任务需要核查正文时按上面的入口获取。 | 用户只要求解读片段时，可基于已给内容回答。任务需要全文却无法取得时，按第四节请用户提供材料路径。 |

论文来源、获取时间、已核版本与可用稳定链接记入 `paper-card.json`，实际阅读位置记入 `reading_progress`。版本不明确时记录未知。工具返回的 `document_id` 用于后续读取同一份快照；引用或续读时还要用已记录的来源与版本核对。不同来源的正文、图表或附录出现差异时，先核对版本。需要用不同版本回答时，分别注明各自支持哪些判断。

## 二、用 tex-mcp 读取 arXiv 源码

1. **打开固定版本**。执行 `tex_open`，记录返回的 `document_id`、实际版本、入口和诊断。后续用同一个 `document_id`。已有快照可用时直接复用。
2. **定位并读正文**。调用 `tex_outline` 找到摘要、引言和实际结论，再用 `tex_read(document_id=..., section=...)` 读所需章节。最小提要可根据已读内容给出，注明依据。讲方法、做综合评价或回答具体问题时，继续读取相关正文、实验、证明与附录。可按标题或标签核对歧义，源码章节编号与 PDF 印刷编号可能不同。
3. **读完所选范围并检查附件**。查看 `items` 中的正文、图表、公式及文献，跟随 `next_cursor` 直到 `truncated=false`。检查支撑当前讲解的直接引用是否取得。若有未知宏、缺图或未解析引用，按需用 `tex_read_file` 核对清单内的原始源码，用 `tex_get_object` 按标签查对象。图像状态为 `ready` 时查看返回的实际图像；表格可先从完整 LaTeX 核对表头、单位、数值和表注。
4. **必要时核对原版面**。子图、裁剪、叠字、公式编号或图注位置会影响解释时，用已核版本的 PDF 查看原页。原始图像文件可能只对应论文图的一部分。

接口、分页和对象处理见 [tex-mcp](../../tex-mcp/SKILL.md)。

## 三、用 pdf-mcp 读取 PDF 或结构化全文

1. **打开并定位**。调用 `pdf_open` 后保存 `document_id`，用 `pdf_info` 查元数据与页数，用 `pdf_outline` 定位章节。目录缺失或只给候选页时，用 `pdf_search` 搜索实际章节标题或图注，再读命中位置。按标题定位摘要、引言和结论，避免按前后页数猜测。已有同版本 HTML 或 JATS XML 时可用其章节结构定位。
2. **按问题读取**。用 `pdf_read` 读取目标页、章节或区域，跟随续页读完所需范围。遇到双栏文字错序或图注归属不清，先用 `pdf_render` 查看原页或区域。需恢复多页布局时，按工具说明对相关页面调用 `pdf_parse`，后续使用同一个 `parse_id`。
3. **核对支撑讲解的图表和公式**。能准确读取表格时，核对行列、单位、关键数值和表注即可。矢量图、复杂表格、子图或关键公式则渲染带图注的页面或区域。仅抽取嵌入位图可能漏图；搜索没命中也可能是文字层提取失败。遇到缺文字层或扫描页，先渲染查看，需要时再按工具说明启用 OCR。识别出的公式和关键数字须对照原页。
4. **记录证据位置**。写明实际读到的章节、公式号、图表号或 PDF 文件页码。文件页码与页面印刷页码不同时分别标明。教学例子的数字与论文原始数值分开记录。

接口、布局解析与 OCR 见 [pdf-mcp](../../pdf-mcp/SKILL.md)。

## 四、材料缺失时怎么处理

1. **TeX 不可用或所需对象缺失**。先查同一版本是否有可访问的 HTML 或 JATS XML，再查对应版本的 PDF。已有文件可直接用；需要从检索结果获取时，用 `list_paper_assets` 查看可用材料，调用 `download_paper_asset` 下载选定的资源，并把返回的 `path` 交给 `pdf_open`。打开后核对标题、作者和版本。文件可解析只说明能打开，身份仍要核查。
2. **只有个别部分读不到**。说明缺的是哪张图、哪条公式、哪个附录或哪段文字，继续使用可核查的材料。有关结论保留为待验证，并在卡片里记下缺项。读取失败、未找到和论文中确实没有该内容是三种不同情况。
3. **全文不可用**。告知用户当前无法完成需要全文的阅读或核查，说明已取得什么、还缺什么。请用户准备指定版本的论文 PDF、TeX 源码或所需附录，并告知这些材料在助手可访问的工作区中的路径。将未完成事项记入卡片，收到路径后从缺少材料的步骤继续。

查论文身份和获取资源的接口见 [paper-search](../../paper-search/SKILL.md)。

## 五、继续阅读

先读卡片中的来源、版本、已读位置、已讲主题、未决问题和续读位置。回查支撑当前问题的原文；同版本且已核实的无关部分无需重读。已有材料换版本、引用发生冲突或前次解释有误时，重新核实相关位置并记录修订。标注本次实际读到的范围，旧笔记没记到的内容仍可回查原文。
