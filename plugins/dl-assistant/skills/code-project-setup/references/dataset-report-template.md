# 本轮数据速览

按实际需要保存datasets-intro.md（可沿用旧文件名），只写本轮用到的资产，不强制每个仓库数据都准备或每个数据集导出固定样本数。人读说明与setup.json记录实际同一范围。

```markdown
# 本轮数据与样本说明
> 实际日期、来源任务/R需求、准备与读取范围、未取得部分。

## {数据资产名称和版本}
- 内容：对象、任务、基本格式和标签/目标含义。
- 本轮用途：训练/评测/测量/转换/接口检查等；对应操作和严格条件，不按“消融/demo”名称自动放宽协议。
- 身份与范围：来源、发布版本、split/分组、原始/派生关系、全量声明与本次实际数量分别列。
- 处理：字段/单位、预处理和转换规则、输入输出版本/脚本及已检查对应关系。
- 与目标协议关系：已核对什么、已知差异、未知及对本轮操作的影响。
- 实际读取：环境/代码/config、loader位置、样本身份、检查结果与限制；链接到setup报告与日志。
- 样本：按真实模态展示必要数量，注明选取方式、ID和对应标签/单位，不代表全量分布。
- 未决：缺失文件、未检查部分、影响与下一步责任。

## 组合数据或跨组件注意事项
身份/划分/单位/预处理是否一致，哪些实际检查、哪些仍未知；不适用则说明。
```

图像可展示真实样本与标注，音频可提供经允许的片段/真实波形或频谱、时长/采样率及目标，文本/表格可展示必要原始片段和字段，其他模态按内容说明。不为套模板伪造图像、标注、例子或测量值。

样本与输出文件按实际访问/分享约定保存，相对路径引用可搬动的文件；不适合导出原始样本时说明限制，用允许的元信息和读取验证记录代替。不因无法导出样本将已验证的读取改写为失败。

真实样本速览有助于理解数据，不证明数据无泄漏、全量格式正确或科学比较有效；这些要靠对应检查的实际范围与证据。
