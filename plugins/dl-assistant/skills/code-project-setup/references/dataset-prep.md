# 数据、权重与派生文件准备

目标是实际资产与选定身份/协议对应，并能支持本轮指定操作。先用survey已查来源/版本和实测任务，再核本机事实；不是重做选型，也不因链接/目录存在而认为就绪。

## 1. 身份、访问与完整性

每份数据/权重记录身份、来源、发布版本/配置、用途、路径、访问条件与来源校验值（若有）。先核现存文件和已运行下载，再执行缺失部分；恢复/续传应核来源与版本相同，部分文件不能覆盖成完整资产。

下载采用本次授权的来源和实际网络策略。认证、限流、网络失败、源不可用分别记录；先检查已有访问能力和有依据的合法替代，不能直接要求用户重下或当成资产不存在。确需人工授权/同意条款时说明具体资源与缺失，不要求在对话粘贴秘密，不绕过访问条件。

获取后核文件大小/格式、可用的发布校验值、清单/分片/解压状态及真实内容。自己计算的内容校验值可标识当前文件，但没有独立参照时不证明是正确原版；镜像来源也须核同一身份。路径存在不证明解压完成、版本正确或loader可用。

大下载按实际调度/任务管理方式运行，引用共享长任务说明；记录日志/退出状态/实际资产，先核运行状态再重启。失败材料与有效资产区分，不自动删除用户文件。

## 2. 格式、预处理与划分

先读真实loader/配置、必要论文或协议，明确样本ID、分组单位、标签/目标、单位、划分、预处理、排除和指标输入。不能假设消融数据可以宽松，具体严格程度由所支持的主张决定。

原始数据保留不改，派生文件保存转换脚本版本、参数和输入/输出身份；修改路径不同于修改标签/单位。标注格式转换先明确字段与坐标/类别/编码/时间单位等对应规则，在已批准范围内执行并检查：
- 转换前后身份、数量及遗漏/重复；有意变化给规则和记录。
- 标签/目标含义、单位与值域，以及必要的逐项对应检查。
- 划分与组身份是否保留，避免同一实体跨不应重叠的集合。
- 实际loader读取后的样本/标签关系，不仅核中间文件schema。

发现错误样本不自动删；有依据的既定过滤按批准协议记录，新的排除规则或标签修正影响研究比较时返回确认。不能因转换脚本无异常就声明语义等价；未检查部分如实保留。

## 3. 小样本与实际读取

按任务取可追溯小样本，记录样本ID、选取方法/随机性、来源split与检查配置。可以选典型及边界案例定位问题，不声称极小子集保持全量分布。检查子集不替代正式训练/评测划分，也不拿其指标对照全量论文数。

用项目实际读取路径核真实输入、标签/目标、单位、长度/形状、batch构造和样本计数；发现空集合、错配或缺文件先核原因，不用输出全零推断唯一原因。有效性检查依据实际数据定义，不要求所有任务都图像/类别标签。

只取得部分数据时记录范围和缺失，仍可做已批准的接口检查，但不能列完整入口/全量结果已验证。准备新科学测量数据或改研究采样设计，交idea-find/iterate设计、execution实施。

## 4. 权重加载

核模型结构/训练阶段/配置与权重身份，采用该实现实际支持的加载方式。记录使用、遗漏、额外或有意重初始化的参数/缓冲区、形状与覆盖范围，不只写key数量或strict标志。

名称映射检查实际对应与未覆盖项；分片/量化/适配参数等按实际结构处理，不强行使用单一通用load片段。加载无报错不能证明身份正确或性能对齐。遗漏关键权重、配置不匹配或需要换初始化时明确影响与授权，不为加载成功擅改结构。

## 5. 速览与交接

只介绍本轮实际准备的数据和样本，依 [速览模板](dataset-report-template.md) 支持图像、音频、文本、表格等形式；遵守实际访问/分享约定，不默认复制全部原始内容。记录来源、实际规模与已取得范围、数据用途、协议一致性和读取限制。

资产状态、读取检查与科学有效性分开。对每个survey实测任务记录实际对象/版本、观察、是否回答了原未知、限制和后续责任；发现选型条件不成立返回选型或研究讨论，不悄悄换数据/模型继续。
