# 论文单实验报告模板

保存为 `experiments/<exp-id>/report.md`。开跑前写前两节，取得证据后回填其余。引用获批计划、实际执行规格和原始记录。

## 本实验要回答什么

{批次、实验 ID、论文主张、计划版本、批准和取证目的。}

## 计划怎样取证

{组别、保持条件、测量、独立重复、解释规则及停止点。}

## 实际怎么做

{实际 run、代码、配置、模型及数据位置。记变更、失败与受阻。}

## 实测结果

| 组别或重复 | 实际读数与单位 | 来源及适用条件 |
| --- | --- | --- |
| {组别或尝试} | {读数、缺项或受阻原因} | {元记录、原始数据、汇总方法} |

## 本实验能说明什么

- **执行**　{完成到哪里，哪些项待执行。}
- **测量**　{可用数据及对照范围，说明缺组、失配和未核处。}
- **证据**　{能回答的问题、剩余解释和适用范围。}
- **交接**　{写作位置、缺项和需要重审的具体内容。}
