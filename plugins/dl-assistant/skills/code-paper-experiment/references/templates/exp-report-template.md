# 单实验记录

先给实验ID/批次、问题、实际观察与限制；执行状态、数据有效性和推断分别报告，阴性/失败/未决可以是本轮结果，不强制一页或一个success标签。

## 目的与原设计

实际计划/设计版本，要减少的未知、探索或确认、必要对照、解释规则与依据；原来相信什么，哪些是待检验假设。

## 实际操作与条件

代码commit/diff、入口与完整命令、配置、模型/数据/测量版本，目标与实际条件及关键检查。重复/seed/attempt身份、选择/排除和恢复来源，资源与实际批准；写清必要事实，不只给跳转。

## 观察、有效性与复算

读数、分母/单位、实际重复、统计/不确定性、来源位置和汇总复核；非数值分析按实际产物报告。哪些数据可信、未检查什么、哪些解释仍无法区分；减少重复不只笼统“降置信”。

## 偏差、变化与交接

所有失败、未执行、条件变化及原因，实际自查与行动影响；原来相信什么、观察到什么、支持到哪一步、判断/限制如何更新。核心问题交iterate，不用换叙述维持原贡献。

所需文件/外部引用及校验值、接收方可用性、缺失影响、资源消耗及下一步建议。文件检查只核所声明范围，不认证研究成立。
