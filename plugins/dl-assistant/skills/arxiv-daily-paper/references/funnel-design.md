# 分轮筛选原则

分轮处理用于分配阅读与评估时间，不承诺不会遗漏高质量论文。每轮保留判断依据，让用户能够纠正筛选结果。

## 信息与判断分开

1. 可核实事实：论文版本、录用声明、代码实际内容、实验设置、报告数字与来源。
2. 证据判断：实验设计是否足以支持论点，是否存在公平性、误差或适用范围问题。
3. 创新性判断：与核查过的已有工作有何差异；未检索时不能确认原创性。

录用声明和元数据需要区分作者声明与已核实事实。代码链接、分类数量、机构、算力、对照数量、引用或热度不单独决定质量，也不赋予免检资格。

## 数量与覆盖范围

- 检查范围为用户选定的分类，主方向决定排序，不自动排除其他方向。
- 优先阅读数量是用户时间预算；补充推荐不限数量。
- agent 尚未完成的检查进入待核查清单，不能为符合目标篇数而记为质量不合格。
- 完整保存原始论文和逐篇处理结果；这提供可复查记录，不代表推断没有信息损失。
- 工作量较大时明确已完成与剩余数量、预计工作，由用户决定继续评估多少。
