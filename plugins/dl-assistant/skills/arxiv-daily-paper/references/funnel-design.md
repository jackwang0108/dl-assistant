# 各轮筛选的目的（arxiv-daily-paper）

所有所选分类使用相同的筛选标准。各轮的具体条件见 `round1-screening.md`、`round2-quantitative.md` 和 `round3-deep-read.md`。

## 判断依据

新投稿缺少引用和社区投票，现有资料不足以客观判定论文质量。前几轮记录可核查的信息，包括是否被会议录用、是否提供代码、对比基线的年份、实验规模和算力投入。创新性留到最后一轮阅读全文后与用户一起判断。后续的社区热度和引用情况由 `hf-trending-papers` 跟踪。

## 筛选顺序

```
获取用户所选分类的全部投稿，获取时不预先筛选
   │
   ├─ 第 0 轮：检查直接入选条件    comment 中有会议录用或代码信息，或有 journal_ref → 直接入选
   ├─ 第 1 轮：读完整摘要          按具体、可验证的技术内容筛选                       约 200 篇 → 约 30-45 篇
   ├─ 第 2 轮：量化评估            下载 PDF，阅读 Experiment 与 Related Work        几十篇 → 十几篇
   └─ 第 3 轮：读全文并判断创新性  候选分三类：主方向相关 / 量化证据强 / 创新性待核   → 个位数篇，由用户确认
        │
        └─ 简报：今日速览、全部入选、主方向精选、其他领域亮点，随后根据用户的问题继续讨论
```

## 所有轮次共用的原则

1. 对所有分类采用同一套标准。用户研究方向只决定哪些论文优先展示，其他领域的论文同样参与筛选，以便发现有参考价值的跨领域工作。
2. 前两轮记录可核查的信息。只在第 3 轮对少量论文判断创新性，并注明结论基于全文阅读。
