# 质量漏斗设计（arxiv-daily-paper）

本文件讲 arxiv-daily-paper 的核心设计哲学——为什么是"质量漏斗"而不是"相关性漏斗"。各轮的具体判据见 `round1-screening.md` / `round2-quantitative.md` / `round3-deep-read.md`。

## 诚实定位

day-1 的新论文没有引用数、没有社区投票，**"质量"无法被客观判定**。本 skill 不是质量神谕，而是用**可量化的代理信号**（中会/代码、对比的 baseline 新不新、实验规模、算力投入）做**透明的渐进初筛**——把"摸得到的事实"标出来，"摸不到的判断"（novelty）留到最后一轮、且拉用户一起定。真正的质量验证（引用/社区热度）是几天后 `hf-trending-papers` 的事。

## 漏斗结构

```
全域抓取（用户选的类目全量，不预筛）
   │
   ├─ 第0道·硬信号直通    comment 含中会/代码/journal_ref → 直接入围
   ├─ 第1轮·摘要粗筛      读完整摘要，按证据强度砍弱摘要（控量入围）      ~200 → ~30-45 篇
   ├─ 第2轮·量化细评      下 PDF 读 experiment+related work，纯客观判据   几十 → 十几篇
   └─ 第3轮·精读判 novelty  精读全文（三通道：主方向 / 全域拔尖 / novelty 破格），拉用户定   → 个位数
        │
        └─ digest：今日速览 + 全部入选 + 主方向精选 + 其他领域亮点 → 交互式探索
```

## 两条铁律

1. **质量筛全域，相关性只分层**。质量这一刀对所有领域一视同仁地切（解决"别在低质量上浪费时间"）；用户的研究方向**只决定哪些额外置顶**，**绝不用来丢弃其他领域**（否则造成信息茧房——而跨域进展恰恰是灵感来源）。
2. **可量化的客观信号优先，模糊判断推到最后**。前两轮只看数得出来的事实，不碰 novelty；novelty 这种主观判断只在第 3 轮、只对个位数篇、且标明"基于精读"。
