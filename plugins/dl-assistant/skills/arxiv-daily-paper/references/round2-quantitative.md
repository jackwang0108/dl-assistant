# 正文与实验检查

对摘要检查后需要继续核实的论文分配互不重叠的任务。每个任务写独立的 `round2/<arxiv_id>.md`，避免并发写相同文件；主 agent 负责汇总。

## 内容来源和版本

先用 `tex-mcp` v2 的 tex_open 确认实际版本，以 document_id 阅读相关章节及直接引用对象，读完续页并记录解析限制；具体工具参数按该 skill 与当前工具接口使用，不依赖这里固定的调用签名。源码不可用时使用 `pdf-mcp`。记录实际读取的版本、章节或页码；不能用不同版本的源码和 PDF 混合支撑同一判断而不说明。

需要保存 PDF 时，从 `raw.json` 的 `pdf_url` 下载到 `pdfs/<version_id>.pdf.part`，验证通过再改为 `.pdf`。ID 用于文件名时将 `/` 替换为 `_`，兼容旧式 arXiv ID。先创建目录，例如：

```bash
curl --fail --location --show-error --connect-timeout 20 --max-time 180 \
  '<pdf_url>' -o 'pdfs/<安全文件名>.pdf.part'
pdfinfo 'pdfs/<安全文件名>.pdf.part'
# 只有下载命令和 pdfinfo 都成功、文件确有页面时才执行：
mv 'pdfs/<安全文件名>.pdf.part' 'pdfs/<安全文件名>.pdf'
```

每条命令检查退出码；`curl` 失败时不继续解析或改名。文件非空及具有 PDF 文件头只是初步检查，还需 `pdfinfo` 或 `pdf-mcp` 的 PDF 解析成功且页数大于零。工具缺失时不能声称已验证；改用可用解析器，或标记待核查。HTML 错误页即使 HTTP 返回 200 也不能通过。已有文件复用前同样检查版本和可解析性。

下载失败时可继续使用已经成功获取的同版本源码，并注明来源；所有正文来源均不可用时只能给摘要级记录，不得标为正文检查通过。数字优先读取正文与表格文本，复杂表格再渲染核对。

## 按研究类型检查

| 类型 | 主要检查内容 |
| --- | --- |
| 方法 | 对照是否相关且条件可比、主要指标与误差、消融能否检验关键机制、成本与适用范围 |
| 理论 | 定义、假设与结论是否匹配，证明与适用条件是否完整；不强求多数据集 |
| 分析或负结果 | 样本与测量方法、替代解释、结果能否重复、结论是否超出观察范围 |
| 数据集或评测基准 | 数据来源、构建与标注、许可、泄漏风险、覆盖范围与评测设计 |

对照的年份和数量、数据集数量、算力、模型规模只作为背景事实，不按越多越好排序。检查对照是否切中问题，不能仅凭“最新 SOTA”标签判断公平性；未查最新文献时注明尚未验证其完整性。

## 代码与复现条件

分别记录：已有可用代码、仅承诺发布、未说明、链接不可用或内容不完整。项目介绍页或空仓库不能算可用代码。仅承诺发布意味着复现仍受限制；未说明不自动意味着工作不可靠。另记数据、权重、环境、训练与评测说明是否足够，无法实际运行时不声称已经复现。

## 检查记录

每篇包括：研究类型、一句话介绍、实际来源与版本、作者论点、主要结果与原文位置、对照条件、证据不足之处、代码与复现条件、已有工作差异的待核实事项，以及建议进入重点全文评价的理由。证据问题用具体描述，不推测作者是否故意回避。

主 agent 汇报已检查、补充推荐、待核查的数量。评估预算不足的单独列出，不因推荐名额用完而判定论文差。
