# 第 2 轮量化评估（arxiv-daily-paper · Step 3）

通过初筛的约 30-45 篇论文全部由子 agent 处理，每个子 agent 负责约 15 篇，通常 2-3 个并行。一律使用能下载 PDF、保存评估记录的 `general-purpose`。每篇阅读 Experiment 和 Related Work，按下表记录可核查的信息，创新性留到第 3 轮判断。

## 保存 PDF

从 `raw.json` 取每篇论文的 `pdf_url`，用 `curl -sL "<pdf_url>" -o pdfs/<arxiv_id>.pdf` 下载到当天目录。子 agent 和第 3 轮共用这些文件。个别 PDF 下载失败时，可用 pdf-mcp 直接打开 URL。若未取得 PDF，仍写评估记录，注明仅依据摘要和元数据，并降低判断置信度。阅读正文时，先用 tex-mcp 打开固定版本的源码。源码不可用时，用 pdf-mcp 读取。

## 阅读正文和主结果表

1. 用 `tex_open(source=<arxiv_id>)` 打开固定版本。源码不可用时直接执行第 4 项。
2. 用 `tex_outline` 和 `document_id` 定位 Experiment、Related Work，再用 `tex_search` 搜索主表和对比描述，例如 “compared with”、“baseline” 或 “GPU”。只读相关部分。
3. 用 `tex_read(document_id, section=...)` 按节读正文。对比方法、年份和数值优先从正文或表格文字提取。主表可从 `tex_read` 返回的表格源码读取，也可用 `tex_get_object` 单独取。
4. 用 pdf-mcp 时，先用 `pdf_open` 打开 PDF，再用 `pdf_info` 核对页数、`pdf_search` 定位主表、`pdf_read` 读文字。仅当主表排版复杂（例如合并列或提取出的文字顺序错乱）时，用 `pdf_render` 渲染整页查看。

## 量化评估标准

| 判据 | 检查内容 | 结果如何解读 |
| --- | --- | --- |
| 对比基线的最新年份 | 对比方法中最新的发表年份 | 包含近 1-2 年的方法，证据较强。只与多年前的常用方法对比，例如 ResNet 或 YOLO，证据较弱 |
| 对比基线数量 | 主表比较了多少个方法 | 比较方法较多，覆盖较广。只与 1-2 个较老的方法对比，标记为需关注 |
| 是否含当前 SOTA | 是否包含领域内公认的最新强方法 | 包含则对比证据较强，缺少则标记为需关注 |
| 实验规模 | 基准和数据集的数量，以及有无消融 | 覆盖范围较广，实验规模更充足 |
| 算力投入 | GPU 数量、训练量和模型规模 | 记录论文给出的量化信息 |
| 相关工作的时效 | 引文中是否有近期工作 | 全部引用较老的工作时，标明可能未覆盖近期进展 |
| 可复现性风险 | 完全未提开源、只与较老的基线对比、消融遗漏关键组件 | 三项同时出现时标记「关键风险」 |

根据开源情况、对比基线和消融内容标记可复现性风险。作者、机构和国籍均不参与判断。开源状态分为**已开源**（仓库已有内容）、**承诺开源**（如 “code will be released” 或 “coming soon”）和**完全不提**。只有完全不提才计为开源风险因素，作者可能在提交终稿后才公开代码。

## 保存评估结果

每个子 agent 将逐篇量化评估记录写入 `round2/<arxiv_id>.md`。包括供简报各处复用的一句话说明（解决什么问题、用什么方法）、主表对比基线、各项量化信息、风险标记和简要小结。只向主会话返回 arXiv ID、一句话说明、各项证据的强弱和是否建议进入第 3 轮。

阅读 Experiment 或 Related Work 时，若作者提出新任务、新基准、新范式或新问题定义，即使量化证据较弱，也标记「创新性待核」，建议作为第 3 轮 C 类候选。这样，仍处在早期、尚无会议录用或充分实验的研究也能进入候选。条件见 `round3-deep-read.md`。

成熟话题同样按这些标准筛选。若论文与当前 SOTA 对比并取得更好结果，保留在简报对应话题。只与 ResNet 等较早的基线对比的论文按现有量化标准筛除。
