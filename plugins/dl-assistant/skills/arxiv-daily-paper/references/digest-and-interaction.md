# 分类、简报与后续讨论

本文件说明怎样把用户的研究范围对应到 arXiv 分类，怎样写摘要速览或完整日报，以及如何把选定论文交给后续的阅读任务。

## 把研究方向对应到分类

用户已指定分类时直接沿用。自然语言方向先给候选分类和覆盖理由，必要时说明缺口。下面是初始映射，可按用户问题调整。

| 方向 | 常用分类 |
| --- | --- |
| 视觉 | `cs.CV` |
| 自然语言和大模型 | `cs.CL`、`cs.LG` |
| 多模态 | `cs.CV`、`cs.CL`、`cs.MM` |
| 强化学习 | `cs.LG`、`cs.AI` |
| 机器人 | `cs.RO`、`cs.CV` |
| 语音 | `eess.AS`、`cs.CL` |
| 统计学习 | `stat.ML`，按题目考虑 `cs.LG` |

研究方向决定展示优先级。仅有主题相关度较低时，仍在本次选定分类中记录其话题。要加入邻近领域时，先说明新增分类及用途。

## 快速浏览 `digest-lite.md`

```markdown
# <UTC 日期> arXiv 摘要速览 · <分类>

## 范围与覆盖
<日期口径、获取时间、返回篇数、已核摘要数、未核和截断情况。所有推荐仅依据标题和摘要。>

## 按话题浏览
<每个话题列代表论文，写 arXiv ID、版本、一句话内容及为何值得先读。>

## 你可能要继续核的论文
<最相关的论文、具体重合或差异、这一步尚不能确认的内容。>

## 待核与后续
<缺材料或预算、完整摘要清单路径、可选后续阅读。>
```

## 完整日报 `digest.md`

```markdown
# <UTC 日期> arXiv 日报 · <分类>

## 今日概况
<日期口径、分类、截断或未结束、返回和去重篇数。各轮已读、待核和未继续数。>

## 优先阅读
<每篇给标题、稳定 ID 和版本、研究问题与内容、优先原因、实际已读层级和待核问题。正文核到的数字带表号或章节。>

## 与你的研究问题有关
<若可能重合，分别指出同一问题、方法或设定的具体重合与尚待核之处。只在已读范围内判断。>

## 其他话题和补充阅读
<按研究类型列值得保留的论文及依据。附它是摘要、正文局部还是全文级记录。>

## 跨日观察（有可比资料时）
<窗口、有效与缺失日期、分类口径、话题篇数及占比、代表论文和限制。>

## 待核清单与来源
<未取得正文、评估预算未覆盖、相关工作待核等。链接 raw.json 和各轮完整记录。>
```

一篇论文的一条记录可以写成「这篇提出新的标注协议。已核数据说明 §3 和主表，主表支持当前数据分布内的结果，跨域设置未找到对照。适合先读协议和数据说明。」作者声称、报告的数字和本次核查判断各自注明来源。

## 根据用户问题继续

用户选一篇精读时，给 [paper-reading](../../paper-reading/SKILL.md) arXiv ID、实际版本、已读位置和未决问题。用户想从速览升级到完整筛选某几篇时，在同一范围内续做这些版本的正文与全文检查。讨论潜在研究重合时先定位实际主张和已有证据，再由用户选择继续精读、发起系统调研或回到研究问题判断。
