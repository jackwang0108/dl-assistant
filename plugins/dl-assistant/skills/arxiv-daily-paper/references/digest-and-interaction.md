# 开场、digest、跨日趋势与交互（arxiv-daily-paper）

## 开场：先定模式 + 对齐参数

先问**模式**：

- **深度漏斗**（默认）：4 轮全跑、下 PDF、完整 digest + 交互探索。适合"想认真筛今天值得读的"。
- **今日速览**：只跑第 0 道 + 第 1 轮（轻量分类 + 标 top），**不下 PDF**，快速给今日全貌。适合"就想知道今天有啥"。

再对齐参数：

```
今天帮你扫 arXiv，先对齐几件事：

① 看哪些领域？可说 arXiv 类目（cs.CV），也可说自然语言方向（我来映射）：
   常用类目：cs.CV 视觉 / cs.CL NLP / cs.LG 机器学习 / cs.AI / cs.RO 机器人 / eess.AS 语音 / stat.ML
   常见方向→类目映射（参考，可叠加）：
     多模态 → cs.CV + cs.CL + cs.MM
     大模型/LLM → cs.CL + cs.LG
     强化学习 → cs.LG + cs.AI
     机器人 → cs.RO + cs.CV
     语音 → eess.AS + cs.CL
② 你当前在做的 idea / 关注的问题？（一句话）—— 用来在结果里【额外高亮】相关论文并做**撞车分级**（撞车警报/强相关/弱相关，见 digest 模板），不会用它丢弃其他领域。
③ 其他领域今日亮点开多宽？（防止视野收窄）只在所选类目内 / 主动越界扫 1-2 个邻近领域找灵感。
④（顺带）日期？默认今天；可指定 YYYY-MM-DD / 昨天。
```

确认后告知："好的，{深度漏斗 / 今日速览}，抓取 {日期} 的 {类目} 全量论文，开始～"

> **今日速览模式**只跑 Step 1 + Step 2（第 0 道 + 第 1 轮轻量分类 + 标 top——top 判据见 `round1-screening.md` 末节），跳过下 PDF / 量化细评 / 精读，产出一个精简 `digest-lite.md`（今日全貌 + 按方向分类 + top 列表）。
>
> **速览后的升级路径**：用户说"第 X 篇细看" → 交棒 `paper-reading`（单篇深读是它的活）；用户说"这几篇帮我按深度漏斗过一遍" → **只针对选定篇补跑 Step 3-4**（下 PDF 量化细评 + 名单确认后精读），不重跑全流程，落盘结构与深度模式相同。

## Step 5 前置：跨日趋势（可选）

写 digest **之前**，直接扫固定产出根目录 `docs/arxiv-daily/` 下各 `arxiv-daily-<日期>-<类目>/trend-snapshot.json`（目录写死，不用问用户要路径）。筛**同分类**、按日期排序，按天数分级：

- **没有历史快照** → digest 不加"跨日趋势"节，标"首次运行，暂无历史对比"。
- **有** → 跟用户说一声"发现近 {N} 日历史，已做跨日对比"，然后分级：
  - **< 7 日**：全部对比
  - **≥ 7 日**：取最近 7 日做"周对比"
  - **≥ 30 日**：在周对比基础上再加"月对比"（最近 30 日）

**判断粒度**（话题标签跨日不稳定，**不比话题名**）：

- **话题级**：今天各簇的 keywords / top arxiv_id 和历史快照重叠 → 重叠高 = "连续 N 天在冒（真趋势）"，今天才冒 = "新出（待观察）"。
- **机构级**：哪些 org 在某方向连续多日出手。

**主会话直接做，不开子 agent**——快照轻量、趋势要全局视野归纳，分片反而割裂。仅当月对比（30+ 快照）且主会话上下文已很满时，才兜底派一个子 agent 读快照吐结构化趋势数据、主会话拿它写叙述。

> trend-snapshot.json 的格式与字段见 `references/trend-snapshot.md`——每次运行结束写一个（落当天产出目录），下次运行做跨日对比时读历史的；它是落盘产物、不是状态中枢。

## Step 5：成 digest + 分层呈现

主会话综合各轮落盘结果，写 `digest.md`，**先全局速览，再跨日趋势，再全部入选，最后行动优先级分层**：

```markdown
# {日期} arXiv 日报 · {类目}

## 今日速览（一屏）
- 漏斗：全量 {N} → 粗筛 {M} → 细评通过 {K} → 精读 {T} 篇
- 今日调性：{一句话整体感觉，如"文档解析/OCR 扎堆，3 篇中了 ECCV"}
- 话题分布：{话题A (n)} · {话题B (n)} · {话题C (n)} …（一行扫完今天在哪些方向）

## 跨日趋势（基于近 {N} 日同分类快照）  [仅当有历史快照时]
- **本周连续冒头**（真趋势）：{话题A 连续 X 天 · 话题B 连续 Y 天}
- **今天新出**（待观察）：{话题C}
- **持续押注的机构**：{OrgX 连续 N 天在某方向}
- **本月主线**（≥30 日时才加）：{...}

## 今日全部入选（第 2 轮通过 · 按话题分组 · 每篇两行）
今天所有过了质量细评的论文全集，按话题归簇，每篇先一句话讲清在做什么，再附关键量化信号：
**{话题簇A}**
- {标题}（arXiv:xxxx）
  - 在做什么：{一句话介绍——解决什么问题、用什么方法（取自 round2 卡片）}
  - 量化信号：{一句话，如"比 2025 SOTA、5 benchmark、开源"} {有复现风险则标「关键风险」}
**{话题簇B}**
- …

## 主方向精选（走满三轮 · 附精读研判）
{精读完的：Ⓐ 通道标签 + 标题 + arXiv链接 + 一句话"在做什么" + 量化信号 + 第3轮 novelty/消融/insight 研判 + 一句"为什么值得你读"}

## 与你 idea 直接相关（额外置顶，不排他）
{开场②高亮的，每篇开头带**相关度分级**：
- 【撞车警报】同问题 + 同思路（判撞标准同 idea-find：问题相同**且**核心思路相同才算撞）——写明「撞在哪」（哪一点同问题、哪一点同思路），提示用户立即交 paper-reading 深读核实、必要时回 idea-find pivot
- 【强相关】同问题、不同思路——写明值得关注的点（它的思路能不能借鉴 / 反衬我们的差异在哪）
- 【弱相关】同领域沾边——一句带过}

## 其他领域今日亮点（防止视野收窄 · 第 2 轮通过 · 通道B/C精读的带 Ⓑ/Ⓒ 标签+研判，其余给速览）
{别的领域今天值得瞥一眼的：每篇带一句话"在做什么"；通道B/C 破格精读的附研判；未精读的给量化信号速览。给跨域灵感}
```

> **详略分层**：主方向走满三轮（精读研判）；其他领域里信号特别强的（通道B）或 novelty 破格的（通道C）也精读，其余只给第 2 轮通过的速览。**所有出现在 digest 里的都至少过了第 2 轮量化细评（或 novelty 破格）**——不放未经质量筛的论文。
>
> **通道标签**：精读过的篇目在 digest 里标注入选通道（Ⓐ 主方向 / Ⓑ 全域拔尖 / Ⓒ novelty 破格）——用户一眼看出"这篇为什么进名单"，尤其 Ⓒ（量化弱但 novelty 破格）不被误当凑数。
>
> **撞车分级的依据**：基于摘要 + round2 量化卡判（深度模式）/ 仅摘要（速览模式）。【撞车警报】必须写出具体撞点（哪一点同问题、哪一点同思路），**不许发空警报**——拿不准是不是同思路就降一级标【强相关】并说明疑点，让用户定。

## Step 6：交互式探索（不结束 skill）

digest 出完**不收尾**，转入**导师 × 学生问答制**，陪用户探索（素材都在 `round2/round3/<id>.md`，按需读盘，不重新下 PDF）：

- 用户对某领域/某簇不熟 → 就着已落盘材料讲清楚（大白话 + 类比），一次讲一块，等用户推进信号再继续。
- 用户问"第 X 篇详细讲讲" → 交棒 `paper-reading`（传 arXiv ID）。
- 用户问"这个跨域话题和我方向有没有结合点" → 就着雷达层聊连接点（呼应 paper-reading 的跨域连接）。**分界**：AD 只做雷达层提示"值得深读"——基于摘要和量化卡的粗略连接猜想；深读全文后的跨域连接（带真实锚点、落在精读笔记里）归 `paper-reading`。
- **纪律**：一次答一块、等明确推进信号才往下、不自动跳、诚实评价不和稀泥、不确定就回读不瞎编。
