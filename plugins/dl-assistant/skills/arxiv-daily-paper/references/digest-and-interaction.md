# 开场确认、简报、跨日趋势与讨论（arxiv-daily-paper）

## 开场确认模式和参数

先问**模式**：

- **完整筛选**（默认）：执行全部 4 轮，下载 PDF，撰写完整简报，并继续讨论。
- **今日速览**：只检查直接入选条件并做第 1 轮简要分类，标出少量推荐论文。跳过 PDF 下载。

再对齐参数：

```
先确认你想看哪天、哪些方向的 arXiv 新论文。

① 看哪些领域？可说 arXiv 类目（cs.CV），也可说自然语言方向（我来映射）：
   常用类目：cs.CV 视觉 / cs.CL NLP / cs.LG 机器学习 / cs.AI / cs.RO 机器人 / eess.AS 语音 / stat.ML
   常见方向→类目映射（参考，可叠加）：
     多模态 → cs.CV + cs.CL + cs.MM
     大模型/LLM → cs.CL + cs.LG
     强化学习 → cs.LG + cs.AI
     机器人 → cs.RO + cs.CV
     语音 → eess.AS + cs.CL
② 你目前在研究什么问题，或准备尝试什么思路？一句话即可。用于突出相关论文，并标注「研究方案可能重合」「强相关」或「弱相关」。其他领域论文仍参与筛选。
③ 只看所选分类，还是也看 1-2 个邻近领域的亮点？
④ 看哪天的投稿？默认今天，也可指定 YYYY-MM-DD 或昨天。
```

确认后告知："好的，{完整筛选 / 今日速览}，我会获取 {日期} 的 {类目} 全部投稿。"

> **今日速览模式**只跑 Step 1 + Step 2（检查直接入选条件、按第 1 轮规则简要分类并标记推荐论文，标准见 `round1-screening.md` 末节），跳过下 PDF / 量化细评 / 精读，产出一个精简 `digest-lite.md`（今日概况、按方向分类和推荐论文）。
>
> **速览后继续阅读**。用户要细读一篇时，把 arXiv ID 交给 `paper-reading`。用户要求对选中的几篇做完整筛选时，**只对这些论文补做 Step 3-4**，即下载 PDF 并做量化评估，在确认名单后精读。输出目录结构与完整筛选相同。

## Step 5 前置：跨日趋势（可选）

撰写简报前，在固定目录 `docs/arxiv-daily/` 下查找各日的 `arxiv-daily-<日期>-<类目>/trend-snapshot.json`。选取同分类的快照，按日期排序，再按历史天数比较。

- **没有历史快照** → digest 不加"跨日趋势"节，标"首次运行，暂无历史对比"。
- **有** → 跟用户说一声"发现近 {N} 日历史，已做跨日对比"，然后分级：
  - **< 7 日**：全部对比
  - **≥ 7 日**：取最近 7 日做"周对比"
  - **≥ 30 日**：在周对比基础上再加"月对比"（最近 30 日）

**判断依据**。按话题和机构分析。话题标签可能随日期变化，因此以关键词和代表论文的重叠情况为准。

- **话题级**：今天各簇的 keywords / top arxiv_id 和历史快照重叠 → 重叠较高时记录持续出现的天数，今天首次出现的话题标为待观察。
- **机构级**：哪些机构连续多日在某个方向投稿。

主会话直接读快照并综合比较。只有在做月对比（30+ 快照）且主会话上下文已接近容量时，才派一个子 agent 读取快照并返回结构化趋势数据，主会话根据数据撰写说明。

> trend-snapshot.json 的格式与字段见 `trend-snapshot.md`。每次运行结束时保存到当天目录，后续运行读取历史文件做跨日比较。

## Step 5：撰写简报

主会话读取各轮已保存的结果，按下列顺序写 `digest.md`。

```markdown
# {日期} arXiv 日报 · {类目}

## 今日速览（一屏）
- 各轮篇数：全量 {N} → 粗筛 {M} → 细评通过 {K} → 精读 {T} 篇
- 今日概况：{一句话概括，例如「文档解析与 OCR 投稿较集中，3 篇已被 ECCV 录用」}
- 话题分布：{话题A (n)} · {话题B (n)} · {话题C (n)} …（一行概括当日的研究方向）

## 跨日趋势（基于近 {N} 日同分类快照）  [仅当有历史快照时]
- **本周连续出现的话题**：{话题A 连续 X 天 · 话题B 连续 Y 天}
- **今天首次出现的话题**（待观察）：{话题C}
- **在同一方向持续投稿的机构**：{OrgX 连续 N 天在某方向}
- **本月主线**（≥30 日时才加）：{...}

## 今日全部入选（第 2 轮通过 · 按话题分组 · 每篇两行）
将通过量化评估的论文按话题分组。每篇用一句话说明研究内容，再列出关键量化信息。
**{话题簇A}**
- {标题}（arXiv:xxxx）
  - 在做什么：{一句话介绍——解决什么问题、用什么方法（取自 round2 的逐篇量化评估记录）}
  - 量化信号：{一句话，如"比 2025 SOTA、5 benchmark、开源"} {有复现风险则标「关键风险」}
**{话题簇B}**
- …

## 主方向精选（附全文评估）
{精读完的：Ⓐ 入选类别标记 + 标题 + arXiv链接 + 一句话"在做什么" + 量化信号 + 第 3 轮对创新性、消融和分析实验的评估 + 一句"为什么值得你读"}

## 与你的研究方案相关（优先展示）
{根据开场第 ② 项突出相关论文，每篇开头标注关联程度：
- 【研究方案可能重合】研究问题相同，且核心思路相同。写明具体重合之处，提示用户立即用 paper-reading 精读核实，必要时回 idea-find 重新评估研究方向
- 【强相关】同问题、不同思路——写明值得关注的点（哪些思路可以参考、与用户方案有哪些差异）
- 【弱相关】属于同一领域，用一句话说明联系}

## 其他领域今日亮点（通过第 2 轮，附入选类别或量化概况）
{每篇用一句话说明研究内容。已精读的 B、C 类论文标注 Ⓑ 或 Ⓒ 并附全文评估，其余简述量化信息}
```

> **简报收录范围**。主方向精选包含经第 3 轮精读的论文。其他领域入选精读的 B、C 类论文提供全文评估，其余通过第 2 轮的论文提供简要量化信息。简报只收录通过量化评估或以 C 类条件入选的论文。
>
> **精读类别**。简报标出精读论文的入选依据（Ⓐ 主方向相关 / Ⓑ 量化证据特别强 / Ⓒ 创新性待核）。
>
> **关联程度的依据**。完整筛选使用摘要和第 2 轮的逐篇量化评估记录，今日速览只用摘要。标为【研究方案可能重合】时，必须说明问题和核心思路具体重合在哪里。暂时无法确认核心思路相同时，标为【强相关】，说明疑点并请用户判断。

## Step 6：根据用户的问题继续讨论

简报完成后，继续用引导式问答帮助用户理解论文。按需读取 `round2/round3/<id>.md` 中已保存的材料，复用已下载的 PDF。

- 用户对某领域/某簇不熟 → 根据已保存的资料，用直白的语言和合适的类比一次解释一个问题，等用户明确表示继续后再往下讲。
- 用户问"第 X 篇详细讲讲" → 把该论文的 arXiv ID 交给 `paper-reading`。
- 用户问"这个跨域话题和我方向有没有结合点" → 根据摘要和逐篇量化评估记录，初步说明可能的联系和值得深读的理由。结合全文核实跨领域联系、记录具体依据和精读笔记，由 `paper-reading` 处理。
- 一次回答一个问题。等用户明确表示继续后再进入下一项。按证据作出明确评价。证据不足时回查材料并说明不确定之处。
