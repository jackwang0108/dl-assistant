# 第 3 轮精读并判断创新性（arxiv-daily-paper · Step 4）

## 三类精读候选

- **A 类 · 主方向相关**。与用户开场说明的研究方向相关，并通过第 2 轮量化评估。
- **B 类 · 量化证据特别强**。各领域均可入选。仅考虑少数同时满足以下多项条件的论文：有会议录用或 `journal_ref`、与当前 SOTA 对比、开源、实验规模大。只有论文或 `comment` 明确写出机构时，机构声誉才可作为权重较低的正向参考。机构声誉不构成入选条件，作者国籍不参与判断。
- **C 类 · 创新性待核**。作者提出新任务、新基准、新范式或新问题定义，并在第 2 轮被标为「创新性待核」。各领域均可入选，量化结果不影响候选资格。这一类让尚无会议录用、实验还在进行或尚未与最新方法比较的早期研究也有机会进入全文评估。

## 精读前确认名单

目标约 5-8 篇。第 2 轮通过十几篇时，按各类候选的证据强弱排序，只把最符合条件的论文列入建议名单，并为未入选的论文简述理由。用户可增删或替换。

在下载用于精读的 PDF、开始精读前，先请用户确认：

```
第 2 轮通过 {K} 篇。我建议精读以下 {T} 篇：

【主方向相关】
- {标题}（arXiv:xxxx）。{一句话说明量化证据}，{一句话说明为什么值得精读}。
【量化证据特别强】（可来自其他领域）
- {标题}（arXiv:xxxx）。{列出支持入选的量化证据}。
【创新性待核】
- {标题}（arXiv:xxxx）。{说明作者提出的新任务、新基准、新范式或新问题定义}。

需要增加、删减或替换论文吗？确认后我会开始精读。
```

用户确认或调整后，按最终名单精读全文。

## 全文评估内容

- 代码和数据是否开源。
- 实验是否充分支持作者的主张。
- 消融是否覆盖关键组件，是否主要检查了对结论影响较小的组件。
- 分析实验是否解释了方法为什么有效，例如是否提供主结果表之外的证据。
- 作者的主要结论是否成立，证据是否充分。
- 创新性如何，例如是否提出新问题、新范式，或在现有工作上做了增量改进。
- 引言是否清楚地组织了问题、方法动机和贡献。

每篇结果写入 `round3/<arxiv_id>.md`，复用 `pdfs/` 中已下载的 PDF。对主观判断标明「基于精读全文」。有疑问时说明不确定之处，与用户一起判断。
