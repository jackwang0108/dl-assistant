# 第 3 轮：精读判 novelty（arxiv-daily-paper · Step 4）

## 入选 = 三条通道

（资格看质量信号强度，不只看相关性——否则会漏掉别的领域今天极佳的工作）

- **通道 A · 主方向**：和用户开场说的方向相关、且第 2 轮量化信号过关的。
- **通道 B · 全域拔尖**：**不论哪个领域**，第 2 轮量化信号**特别强**（紧门槛：中会/journal_ref + 比最新 SOTA + 开源 + 大规模实验，多项齐备的极少数）就破格进精读。机构声誉只作**弱正向先验**（仅在论文/comment 明确写出机构时用，不靠猜作者国籍——**不设任何国别信号**），锦上添花、绝不当门槛。
- **通道 C · novelty 破格**：**不论领域、不论第 2 轮量化强弱**，只要 claim 了**新任务 / 新 benchmark / 新范式 / 新问题定义**（第 2 轮子 agent 标了"novelty 破格候选"的），破格进精读。**这是对"质量前置筛"的 novelty 补偿**——day-1 的核心价值就是 novelty，而越 novel 越前期（没中会、实验还在做、baseline 还没比到最新），纯量化关会把高 novelty 低质量信号的论文刷掉。没通道 C，漏斗会系统性偏袒"成熟增量"、漏掉"早期 novel"，和信息茧房是同一类病。

## 精读前确认（硬规则）

**名单规模：目标 ~5-8 篇，宁缺毋滥。** 三通道是**入场券不是保送**——第 2 轮通过十几篇时，同通道内按信号强度再排一次，只带最强的进名单（精读全文是整个漏斗最贵的环节，量一爆就拖垮）。摆名单时对被压下的篇目附一句「为什么没进」，透明可纠（用户可以说"那篇也加上"）。

下 PDF 精读之前，先把名单摆给用户确认——

```
第 2 轮通过 {K} 篇。我建议精读以下 {T} 篇：

【主方向】
- {标题}（arXiv:xxxx）— 为什么留下：{量化信号一句话}；为什么值得精读：{一句}
【跨域拔尖】（不在你主方向，但今天信号特别强，建议也看）
- {标题}（arXiv:xxxx）— 为什么破格：{硬信号叠加情况}
【novelty 破格】（量化信号不一定强，但 claim 了新任务/范式/新 benchmark，值得精读验 novelty 成色）
- {标题}（arXiv:xxxx）— 为什么破格：{claim 了什么新东西}

要调整吗？（可加/减/换；说"就这些"就开始精读）
```

用户确认/调整后，才对最终名单**精读全文**。

## 精读看什么（这一轮才碰主观判断）

综合看：

- 代码/数据是否开源
- 实验是否充分支撑 claim
- **消融实验是否避重就轻**（有没有故意不消融最关键的组件、只消融无关紧要的）
- **分析实验是否有足够 insight**（除了刷点，有没有揭示"为什么 work"的分析；还是只有 main table 没有 why）
- claim 立不立得住、是否 solid
- novelty 如何（是新问题/新范式，还是增量）
- intro 的 story telling 质量

每篇写入 `round3/<arxiv_id>.md`（复用 `pdfs/` 里已下的 PDF）。**主观判断标明"基于精读全文"**，拿不准时拉用户一起定，不替用户拍"它一定好"。
