# 重点论文全文评价

## 确认名单

默认优先阅读 5–8 篇，按用户预算调整。推荐理由可为与主方向相关、值得关注的证据、可能存在新的研究问题或方法；这些是选择阅读顺序的理由，不是免检资格。

展示论文标题、arXiv ID、已读范围、推荐理由与尚待核实之处，同时给出补充推荐和待核查清单。用户确认或调整后，再对选定论文阅读全文。当天值得关注的论文多时如实报告，不用名额截断保留清单。

## 分开评价两件事

### 证据支持程度

- 明确作者的主要论点。
- 检查实验或证明是否支持它，对照是否适当，是否存在误差、替代解释或适用范围限制。
- 给出“有支持证据 / 证据不足 / 存在相反证据 / 尚未核实”的判断，附原文位置与理由；作者报告的结果不等于独立复现。

### 与已有工作的差异

- 分别记录作者声称的新内容与已核实的差异。
- 给出“待核实 / 有明确差异 / 已有工作已覆盖”的暂定判断，列最接近的已核查工作及稳定标识。
- 说明差异是什么、为何可能重要，以及检索或阅读覆盖范围。只读当前论文不足以确认创新性；新任务措辞也不保证真实差异。
- 找不到可比来源时保持待核实，不编造相关论文，也不把证据充分自动转成创新点。

## 保存

写入 `round3/<arxiv_id>.md`：来源版本、阅读范围、证据评价、已有工作差异、复现条件、局限、推荐理由和未决问题。未读完全文就标明实际范围，不写“基于全文”。

全文阅读在这里服务于筛选；用户要求逐节讲解、推导或完整理解时交给 `paper-reading`，传 arXiv ID、版本与已有记录。
