# 按目标选择验证与解释不确定性

先确定要验证哪个参考结果/行为、实际条件和用途，再选择评测、训练或必要组件检查。不要按“training-free/重训”二分后机械执行相同流程。

## 目标与证据需要

| 目标 | 相关验证 | 边界 |
| --- | --- | --- |
| 已发布权重的评测结果 | 权重身份/config、数据/协议/指标与实际评测 | 不验证训练过程；同一指标接近不认证所有输入/实现 |
| 原条件的训练结果 | 训练数据/目标/初始化/更新/选择与实际最终评测，必要重复 | 评测检查有帮助但不代替训练；原条件未达到不能标原条件已复现 |
| 改条件的参考实现 | 明确改变的模型/数据/预算等、相应行为与比较 | 是该条件下结果，不按论文原数自动判成功/失败 |
| 数据/测量组件 | 对应定义、已知答案或可信参照及实际行为 | 不拿无关benchmark数字认证测量正确 |

官方权重缺失或不匹配时说明影响，核是否有相关替代参照或只能取得局部证据。没有官方权重不自动判无法研究，也不把其他checkpoint当原模型。已有环境但缺setup文件时补最小来源和前置核实；缺实际准备条件返回setup。

## 比较之前先核可比性

参考的实际身份/版本、目标行、样本/分组/split、预处理/采样/增强、模型/权重、指标实现/单位/聚合、训练/选择流程及随机性是否明确？逐项写same/different/unresolved/not_applicable及证据。不以同名指标、相同seed或相同有效batch自动宣称相同条件。

- 目标是原条件复现但实际存在实质差异：先记录差异，不能仍填原条件consistent。
- 明确研究另一条件：保留原参考和新条件，选择适合新目标的依据，不擅自调整比较界限来“过关”。
- 条件不明：结论先not_comparable或insufficient_evidence，提出最有信息的查证，不填默认数值门槛。

## 差异来源要分开

数值/实现误差、训练运行间随机性、固定权重评测随机性、数据抽样/组相关性、协议差异分别记录。给每个实际重复的设置、读数和实验单位；样本数不等于独立训练次数。不同模型、schedule、选择流程的checkpoint不能直接混算成同配置波动。

论文的±数值先核它是什么、重复单位/次数与统计定义；不能自动把标准差当置信区间或复现允许差异。未报告或无法取得时说明未知。自己估计的波动只对应当前条件，不能变成所有未来方法差值的统一阈值。

## 预先安排比较与预算

- 与当前目标有关的等价/允许差异界限须有来源：定义/数值误差要求、任务实际意义、已核对的参考协议或其他明确依据。解释支持哪种结论，不按分类/检测等任务名称套默认band。
- 区分描述性读数、统计不确定性、实际意义和原条件是否一致；数值差很小不证明是噪声，统计未显著也不证明等价。
- 重复/seed/抽样次数按目标、已有证据和预算安排，不统一要求某个数量。单次可交，但不伪造运行间不确定性；信息不足则明确不足。
- 有配对设计时说明配对单位和依据，不把同seed自动当有效配对；分析方法与独立性假设相符，不默认mean±std或2×std裁决。
- 若采用序贯追加，先明确追加/停止与解释规则；否则不能看差距大小再随意追加直到接近参考或显著。保存全部尝试和偏离原计划的理由。
- 原文仅报最佳值、测试复用、模型选择或调参过程不明时说明可比限制，不拿自己的均值直接宣称复现/未复现同一个统计目标。

无法合理给出数字界限时可以做有依据的行为检查或描述性比较，不要求每个目标都产“通过/不通过”。没有足够依据不能称性能等价或同一机制。任何拟合/统计计算本身也需检查适用条件与输入身份。

## 修复、差距与停止

差距可以来自实现、条件、来源记录、测量或随机性；证据未定不强写唯一原因。按trust-traps记录竞争解释，选择能区分重要原因且成本合理的检查。小样例修复后重跑受影响部分，不自动推翻所有已验证结果；数据/协议变化则重核相应可比性。

不能为追论文数做无边界超参搜索、挑seed/最佳checkpoint、改变测试样本或覆盖原计划。协议/实现确需修正时按实际授权和影响讨论，保留旧结果；初始化/官方或自训权重按目标选择，不统一替换。

预算不足、反复无新信息、关键参照不可得或需改变研究设计时，可以交付差距和未决并暂停。重大验证是否交execution或后期实验由目的/阶段判断，不按机器或“全规模”名称决定。
