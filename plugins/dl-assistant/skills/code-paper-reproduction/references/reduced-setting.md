# 可选的低成本验证配置

保留文件名供旧引用定位。**不再执行自动scaling law拟合、强制多点扫描或规模外推认证**；不再产scale_sweep/scaling_law_confirmed，也不使用它们决定新方法去留。旧项目原始文件保留，旧标记只作历史记录，不转成新证据。

## 先明确用途，再决定是否需要

配置应服务一个具体目标：更低成本检查某种行为、在明确的小问题条件下取得参考结果，或为下一轮研究准备可执行条件。它不是reproduction的强制交付，预算不默认固定小时数；没有低成本配置仍可交真实复现结果/未决并讨论实际迭代方式。

检查成本、原条件复现、改条件研究、跨规模迁移是不同问题。不要把缩规模配置称为原条件“等价复现”，也不让它继承原模型全部可信度。

## 先判断哪些条件不能缩减

采用共享 [研究条件记录与检查](../../dl-assistant/references/research-conditions.md)。先记录最终目标和当前用途，再把各条件分为必须保留、本轮可缩减、影响未知；不能先选便宜配置再补理由。关键现象、必要输入/容量/数据组成/训练阶段及测量能力必须得到保护。未知可以通过有范围的探索核查，但该配置不因此取得目标假设的筛选资格。

每次使用都绑定当前问题/假设；新方法或假设变化后重新检查。没有有效缩减时如实报告资源限制，不强制交一个 reduced 配置。

## 改哪些条件，逐项说明

数据量/组成、模型、输入尺寸/长度、batch、训练长度、优化/调度、精度等都可能影响解释，按当前问题评估，不预先禁止某一轴，也不把只缩数据视为无影响。

每项保留原配置与新配置、原因、受影响机制/数据/更新/测量条件和未知；说明仍能回答什么、什么已不再相同。epoch相同不保证相同更新次数、数据暴露或收敛；梯度累积等设置也不能自动抵消所有条件差异。任何换算/调度调整须有理由，不按通用公式机械修改。

条件改变后原参考数可能不适用，须独立定义本轮预期/参考或明确仅作描述。问题关键条件被破坏时不采用该配置，或先讨论新问题，而不是仍用原贡献理由继续。

## 验证范围与外推限制

实际运行并记录对应行为、基线结果、重复/不确定性及成本，只支持当前配置与所查范围。小规模表现本身可能有研究意义，但须以明确问题和证据说明，不能靠“小规模”自动降级或自动升级。

- 基线在几个规模上性能接近或可拟合，不证明新方法收益/排序能推广。
- 一个留验点预测吻合不认证某条普适规律，也不说明所有架构/超参改动都有同向效果。
- 一个已知改动在两种条件下同向，只支持该改动在所测条件的观察，不认证未来候选。
- 小规模无提升不能自动淘汰原规模假设，小规模提升也不能直接推出原规模有效。

跨规模关系若本身值得研究，由iterate明确假设、比较设计、参照和成本，execution取得相关证据；不在本skill默认安排baseline扫描、消融或idea试探。已有相关研究证据可引用，但核对对象/条件/范围，不能继承一个全局外推布尔值。

## 与用户确认和交接

先说明节省什么成本、牺牲什么条件、实际依据和未知；仅在已批准范围执行。预算、目标或科学比较变化返回讨论，不强求最大预算点或固定候选数量。

reproduction.json的low_cost_configs按需记录id、用途、原协议/target、新配置/差异、condition_review_ref（条件记录路径和版本）、必须保留项的实际落实证据/未知、实际运行与结果引用、适用范围、不能推断内容、目标验证触发点、预算/批准和未决事项。未运行的建议标proposed，不列已验证入口。无需求时空数组，不为填满模板制造配置。

若已有旧reduced_setting或noise_floor：保留历史来源、原始条件/读数，取消自动外推/2×std判据；实际使用时重新核本轮目标和证据。不批量改写历史配置或删原实验。

## 三种情况的边界

| 情况 | 可说明什么 | 不能说明什么 |
| --- | --- | --- |
| 小输入/短步数的组件检查 | 该输入条件下的预期行为 | 完整训练收敛、全量性能或新方法方向 |
| 明确小条件的完整参考运行 | 该条件下的实际结果和不确定性 | 原配置结果、原方法最佳性能 |
| 针对跨规模假设的研究 | 按实际设计取得的关系证据和限制 | 对全部新方法/规模的自动推广 |
