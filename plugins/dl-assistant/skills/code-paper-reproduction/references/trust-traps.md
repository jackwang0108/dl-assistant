# 差距调查与证据范围

核查结果与参考不同或接近时，都先确认身份、条件、实现与证据范围。以下是按当前疑问选用的调查项，不按未经证实的“命中率”固定顺序，也不要求全部排除才能保存未决结论。

## 对应目标核哪些条件

| 项目 | 核查内容 | 不能据此推出 |
| --- | --- | --- |
| 参考身份 | 原文/发布版本、表格行/行为、配置、报告是单次/最佳/均值 | 标题或数值相似就代表同一目标 |
| 指标与测量 | 实际调用/定义/参数、单位、分母、聚合、样本/分组、必要已知答案 | 同名指标或某个答案正确认证全部实现 |
| 数据与输入 | 真实加载split/ID、预处理/增强/排除、版本、输入条件和潜在重叠 | 数字高就证明泄漏；没发现问题就证明无泄漏 |
| 模型与权重 | 结构/训练阶段、来源/config、实际使用与遗漏、原始/平均/被选择权重的身份 | 官方发布必是论文那次训练，strict成功就身份正确 |
| 评测协议 | 样本生成/筛选、输入尺寸/长度、增强/采样/解码、次数与聚合 | 加了协议得到更近数字就证明修复正确 |
| 训练条件 | 数据/目标、初始化、更新、batch/同步/归约、精度、优化/调度、增强、保存/选择 | 有效batch相等就所有训练条件等价；评测数接近就剩余差距一定来自训练 |
| 不确定性 | 随机来源、实验单位、重复/选择过程、参考统计含义 | 未固定确定性的小gap一定是噪声；mean±std自动判断是否复现 |

遇到条件差异先说明它影响什么，不能称“差异可解释”就当原条件复现成功。指标近似、明显更高、更低或极端读数都是观察，是否异常依据实际任务与原预期，不凭零分/满分或优于论文自动判错。

加载采用实际模型支持的方式；参数映射/有意初始化须有依据、授权和对应检查，不强制一律strict=True，也不允许无说明忽略关键权重。EMA等状态、恢复来源和选择过程按事实记录，不替作者猜测。

## 调查记录结构

保存alignment.md中的逐目标记录：
1. 观察：原参考、实际结果与条件，具体来源和读数；来源声明、本次测量与推理分开。
2. 竞争解释：各解释依据、反对证据、尚不确定的前提；不把最先提出的解释当根因。
3. 已检查事项：读过什么代码/配置、跑过什么、覆盖范围，哪些解释只受限制而非完全排除。
4. 下一项检查：能区分什么、不能区分什么、所需成本/授权；必要时不继续实验。
5. 当前结论：已解释部分、仍未知、对具体使用范围的影响和返回责任。

数值接近也核这些对应条件，防止条件差异互相抵消。原因未知允许保留，不无限追到“唯一根因”，不把调查记录完整当科学解释成立。

## 组件诊断要有适用前提

采用setup的 [行为检查规则](../../code-project-setup/references/numeric-sanity.md)，已完成且条件对应的检查可引用，不重复写一套通用正loss/非零/必下降要求。

- 小样本学习检查：先核任务、目标、模型/正则与优化条件是否允许预期行为。能拟合不证明训练实现整体正确，不能拟合也不直接证明bug；不为诊断自动加容量或改初始化。
- 初始目标值：只有在初始化/预测分布/目标/归约等条件明确时才推导参考；不能把一个分类特例当所有任务默认量级。偏离先核条件，不能自动改bias或目标来“修”数值。
- 常量/打乱输入：先明确它在当前任务会破坏什么、是否仍有其他信息通道；结果接近可能有多种解释，不直接宣布标签泄漏或输入未使用。
- 实际输入检查：核送进计算的真实样本、标签、预处理、单位与对应关系；可视化仅覆盖所看范围，不是无歧义证明。音频/文本/非图像任务采用适合的检查。
- 依赖/梯度：依据模型实际设计核预期依赖、冻结和分支；跨样本交互可能是有意的，不能统一要求别的样本梯度为零。梯度为零还需区分结构依赖和当前输入数值条件。

诊断设置若关闭增强、改变输入/容量/目标等，另存配置和依据/批准范围；结果只支持该诊断条件，不认证原训练。涉及新科学假设/干预实验时交研究设计与execution，不借“诊断”绕过记录和授权。

## 何时继续、修正或返回

可按已有授权修复含义明确的工程问题，保留版本和受影响重验。数据/加载/计算/协议影响不明时先核证据并讨论；核心研究设计改变返回idea-find/iterate。缺环境/资产回setup，缺候选适配性回survey；预算不足或重复无新信息时可暂停并交未决。

不要为了接近参考调超参、改测试划分、只保留好seed或覆盖原预期；没有异常也不推导所有用途可信。原结果无法复现可如实交付，不把执行失败写成假设反证，也不在条件不明或偏弱实现上直接宣称新方法提升。
