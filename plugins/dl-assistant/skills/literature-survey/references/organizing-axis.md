# 文献分类与详细阅读分工

“分类维度”指按研究问题、方法、假设、评测对象或时间等组织文献的依据。先用实际文献内容提出暂定分类，再向用户解释其用途与局限，不能把分类方案当作领域天然唯一结构。

## 分类检查

- **内容有依据**：标题和短摘要可初分，代表工作、边界案例、新论文核查到足以确认类别的正文或摘要。不要仅以最高引的十篇决定领域结构。
- **允许交叉**：论文可有一个主类别和多个标签，跨类别比较不被丢弃。
- **允许不均衡**：大类、少数新方法和独立论文可以保留，数量差异可能来自真实分布或检索不足，不能先认定分类错误。
- **可用与覆盖限制明确**：分类应帮助用户回答问题，未分类项和不确定项显式保留；候选池覆盖不等于领域覆盖。

类别数与层级随需要，不固定 3–5 类，也不与 agent 数绑定。一个 agent 可处理多类，大类可分多个批次。小样本可平铺，不能为了类别数量创造假区别。

用户确认分类后指定详细阅读论文、问题、范围、预算与独立输出文件。新增文献能归入现有类时补记录；涉及合并、拆分或改变主要比较结论时先展示新证据、与用户确认。

## 关系类型分开

时间先后不等于因果或继承。声称基于前作、替代或扩展时给具体引用/原文依据；没有明确关系的工作可并列发展。阅读前置是教学安排，可以晚于历史发表顺序，不能拿它证明方法继承。

主 agent 负责综合比较、核查冲突和统一报告。子 agent 的材料可复用，实质性断言要能追到原文，不要求主 agent 只能依赖摘要或绝不回读。
