# 检索来源选择

来源按研究范围、用途、时间和实际可用能力选择，不把固定平台组合当所有任务的硬要求。正式计划写明采用与未采用来源的理由、可能遗漏的社区；用户指定历史范围时不强制扩展到近期。

- `paper-search` v2 提供身份核对、多表达式检索、引用/相关论文与实体查询。先 get_capabilities 核实际来源能力，按日期类型设置过滤；get_query_results 只读快照，extend_query 才扩展上游。保存具体 snapshot_id 的导出及 source_reports/coverage，不将本地结果读完视为搜全；实际参数和预算见该 skill，不在此重复维护。
- arXiv 适合覆盖其所收录领域的预印本，关键词、别名和分类会影响召回；记录提交日/更新日等实际过滤口径，不称为全部科研论文。
- 综述、正式会议/期刊目录和引用链可补充研究结构与历史工作，重要归纳回到原始论文核查。
- HF Papers 为社区选择的补充样本，不替代广泛学术检索；不保证语义搜索优于关键词，也不保证不漏同义词。详见 `hf-papers.md`。
- 不在 arXiv 或 HF 广泛发表的领域选择合适数据库与官方来源，不为凑平台而查询无关来源。

学习理解侧重清楚的综述和代表工作；研究定位与找方向侧重近期与最接近工作的补查；技术比较侧重数据、成本、评测和适用条件。熟悉度影响解释与历史铺垫，检索范围仍以批准计划为准。

论文引用数、平台投票和 star 只作各自来源的观测，记录来源和时间；不能单独决定质量、里程碑或采纳程度。机构与作者信息不全时写未知。

某来源失败时保留状态，按授权用其他来源继续，报告缺失范围。全部失败时先诊断网络、认证、工具或源站问题，不将其统一解释为关键词不好。合法空结果、未运行和失败分别记录。
