# 在调研中使用 HF Papers

HF 作为补充来源，是否查询及查询范围随批准的调研计划确定。有限搜索、日报和热门列表都不是主题完整枚举，不能保证同义表述全部召回，也不能以平台 AI 摘要代替原始论文。

参数、版本核对、安装认证、日期及错误处理复用 [HF CLI 参考](../../hf-trending-papers/references/hf-cli.md)，本文件只说明调研用途，避免重复维护命令保证。

```bash
hf papers search '<研究问题或关键词>' --limit 20 --format json
```

先看实际版本帮助，按计划尝试概念、方法和任务别名。搜索无服务端日期过滤时，客户端按已确认含义的日期字段筛选；在有限结果中后筛日期不证明该时段完整。日报日期、论文发表时间与指标获取时间分开。

记录查询、limit、实际数量、获取时间、错误和截断限制，与其他来源同样进入 search 记录与 pool。未知分页能力不称为全量。未执行、失败、空结果分开呈现；日期不可用不自动回退或换为热门查询。

`ai_summary` 和 `ai_keywords` 可作为扩展检索词的建议，标明平台生成并用原始标题摘要核对；upvote、star 不参与论文质量的直接判断。历史列表上的当前指标不能当历史关注度。
