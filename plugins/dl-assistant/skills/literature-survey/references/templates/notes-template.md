# notes/<子领域-slug>.md 模板（Step 4 深挖子 agent 落盘 · 中文）

notes 的两重身份：深度后备（主会话看摘要不够时读）、Step6 写 `report.md` 和 `reading-list.md` 的**素材来源**。

**分工：逐篇笔记记单篇的事实，写作素材包做跨篇的归纳**——两边内容不重复。演化关系（谁基于谁、谁解决了谁的坑）是单篇事实，只记在逐篇笔记里；素材包里的机制骨架、差异点是从这些单篇事实里归出来的，不再抄一遍。

## 结构

```markdown
# {子领域名}（轴：{axis}，用途：{purpose}）
```

## 「记到什么程度」：浅笔记 vs 深笔记

同一段话，两个深度——子 agent 交右边那种：

```markdown
# 浅（不合格：高级摘要，主会话还得回读原文）
- 核心 idea：提出 Latent Diffusion，在 latent 空间做扩散，效果好。
- 关键设计：用了 VAE 压缩，用了 cross-attention 做条件控制。

# 深（合格：主会话不回读原文也能做机制归纳）
- 核心 idea：把扩散过程从像素空间搬到 VAE 的 latent 空间——关键假设是
  「图像的语义内容在低维 latent 里基本无损」，假设成立才能用 1/10 算力换几乎不掉的质量。
- 关键设计：VAE 下采样 8 倍——再多压细节崩、再少压省不动算力，8 是实测的甜点；
  cross-attention 注入条件——因为条件来自任意模态（文本/布局/深度图），
  attention 比 concat 更能对齐异构信息，这也直接解锁了后来的多条件控制工作。
```

判断标准：**主会话不回读原文，能凭笔记写出机制层面的归纳和对比**——够不到这个标准的笔记，就是嚼成了高级摘要，打回重记。

## 纪律

- 写作素材包是给主会话的**弹药，不是成稿**——不要写成连贯的报告段落（主会话不会直接嵌，写了也白写）；要点化、信息密度优先。
- 逐篇笔记与素材包**不重复**：单篇事实进笔记，跨篇归纳进素材包；素材包里的每句归纳都应能指回某几篇笔记。
