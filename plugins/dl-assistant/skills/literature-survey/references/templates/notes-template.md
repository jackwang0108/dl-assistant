# 逐篇笔记与跨论文归纳

每个详细阅读批次独立 Markdown 文件，注明用户用途、类别及分配论文，不同时写累计文件。笔记描述实际已读内容，不借例子编造论文的数值、假设或设计动机。

## 逐篇记录

- 稳定身份、标题、版本、来源链接及实际阅读位置。
- 本文问题、作者声称的贡献、实际机制/证明与关键条件。
- 主要证据：设置、对照、指标或假设、结果、适用范围；数字给实际原文定位。
- 证据充分程度、未知项与限制，区分作者解释和读者推断。
- 已核查的跨篇关系：引用、扩展、并列或待确认，不从时间先后推断继承。
- 阅读推荐理由、必要前置和具体阅读问题。
- 作者的 limitation/future work、后续已有解决线索与检索范围。

正文不可用时保留实际阅读深度，不能写成完整核查。公开资源缺失与研究无效分开。

## 可追查的跨论文比较

按研究问题组织比较表：论文/版本、方法、假设、数据与划分、评测协议、指标、成本条件、限制和来源位置。来自不同模型、训练数据、硬件、指标定义或预算的数字标为不可直接比较；无法对齐时不强排名。成本与采纳程度无证据则未知。

跨篇归纳每项指回已核查的单篇证据，注明可能的替代解释及未读部分。关键结论、冲突和不明确设计理由须允许主 agent 回查原文；子 agent 的概括不能替代证据。

## 待验证问题

每项记录来源类型（作者声明/跨篇归纳/推测）、具体论文位置、现有证据、是否有后续工作、检索截止与未知范围。论文曾提出问题不代表现在仍未解决，不在此替用户确认创新性或选题价值。
