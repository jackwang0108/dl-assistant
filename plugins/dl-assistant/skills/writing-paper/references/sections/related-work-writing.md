# 相关工作

向读者解释与本研究有关的已有认识、方法、证据与差异。分类服务于理解真实关系，不以本文必然占优为终点，不设引用篇数目标。

- 优先直接相关、奠基、竞争、反对或限制本结论的工作；按问题、假设、条件、方法或测量对象组织，选择与论证有关的维度。
- 每类先概括真实共同点，再说明关键差异；最接近工作可逐篇比较，不为凑引用只列名字。
- 区分原作者明确报告的限制、本文推断和本项目新实验。没有找到先例不等于无人做，未取到原文不写确定性否定。
- 与本文比较时写具体对象、条件和证据；已有组合并不因重新命名变成新颖，细微差异也不自动重要。
- 数据集、指标、baseline 和理论背景的关键句同样核原文，不因 supporting 标签跳过。

按 bibtex-on-the-fly.md 记录每条引用的身份、使用位置和支持关系；元数据只能确认身份。摘要、引言中的相关工作判断应与本节一致。新文献影响核心新颖性或价值时返回研究判断，而非只加一条引用。
