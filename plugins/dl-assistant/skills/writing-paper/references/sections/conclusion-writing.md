# 结论与研究边界

回答具体研究问题，概括证据带来的认识变化及其意义。不要只重复模块/实验清单，也不在结尾新增未经验证的机制或更大范围承诺。

- 区分已观察事实、推理、理论结果和仍未回答的问题；阴性/反例/局部发现可以是主要结论。
- 说明适用条件、反证、关键限制和对结果解释的实际影响；正文和结论边界一致，不在结论才首次承认核心失败。
- 后续工作应是明确未知或可能研究，不能成为当前核心贡献成立所必需却尚未完成的依据。
- 与摘要、引言、结果和 evidence-map 对照；新颖性和重要性依据与当前范围一致，不因结果变小仍沿用原大问题意义。

语言准确直接，既不夸大也不删去真实结果。无需强制“升华”、优势反转或未来积极承诺。
