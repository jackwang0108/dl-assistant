# 实验或测量的设置

写清研究问题、设计如何取得证据及其限制，不预设要证明方法有效。实验数量、数据集数量、seed 和消融根据问题决定，不统一要求多个 setting 或三种必备实验。

## 每项研究需交代

- 目的与问题/假设、探索或确认、原设计与实际修改。
- 数据来源/版本、采样与分母、划分、预处理/排除、泄漏检查、样本覆盖；不只写数据集名称。
- 模型/权重/初始化、实现版本、配置、训练更新/数据暴露/阶段、优化与调度、精度、设备和成本，按解释/复现所需提供。
- 具体对照及选择依据、报告值还是自跑、可比性与不一致条件；不强制同期所有 SOTA，也不能弱化关键对照。
- 指标定义、单位、方向、统计量/不确定性、重复和选择/停止规则。公平条件由问题决定，不把同 seed 或所有参数相同当作充分证明。
- 研究条件记录：目标与实际差异、必须保留项的证据/未知、reduced 的适用范围和不能外推内容。

解释设计能区分什么、不能区分什么。控制多个变量需足够设计支持，不能靠文字声称唯一机制。不能取得目标关键条件时返回研究设计，不能只把缺口藏进设置。

描述实际发生内容，未执行项标计划。固定配置和参数选择的数据应可追查；新观察形成的新分析明确标为事后。
