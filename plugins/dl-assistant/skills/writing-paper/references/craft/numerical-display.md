# 真实数据的图表与数值展示

## 来源与统计

从实际数据文件/分析输出生成图表，保存脚本、版本与所需参数。每个结果关联实验、指标、条件、分母、单位、样本/seed、缺失与排除、选择规则及不确定性类型。重复、标准差、标准误和置信区间不能混用；不强制多 seed 或通用显著性阈值。

使用 canonical-values-template.json 登记出现位置和来源。差值、比例、均值和区间先由可审查脚本计算并保存输出，再指向对应字段；不能因为某值在全局清单出现过就任意复用。先核数据有效性，脚本可读不等于科学有效。

## 选择表达

- 表用于精确数值与多条件对照；列标题注明指标、单位、方向、条件及统计量，行分组明确，引用报告值与自跑结果分开。
- 曲线用于有意义的自变量与趋势；无真实顺序的运行 ID 不画成连续关系。
- 散点/分布图注明样本和重复；少量点直接展示实际点，不用平滑图制造确定性。
- 热图注明坐标、色阶与范围；定性样本说明选择规则和处理，对不同方法使用一致裁切/缩放，不能只靠挑有利样本暗示总体优势。
- 柱形图长度表达大小时使用合理零基线；截断轴明确标示并解释，不以缩轴夸大微小差异。对数轴、双轴和平滑处理需说明目的和影响，不采用通用“数据占轴比例”。

## 清晰与可恢复

用可区分类别、顺序或正负的颜色/线型/符号，灰度下检查；不只靠红绿。单位、精度、误差定义及表头清楚，最优标记不掩盖不可比条件或不确定性。有效数字随测量精度选择，不机械统一所有指标。

按实际模板的物理尺寸设计图表，检查文字、图例、误差条和裁切。矢量图优先保留可编辑源及 PDF/SVG 等适用输出；图像数据允许合适分辨率的栅格格式，不把截图当可恢复数据源。

图表、caption 与正文表达同一具体观察；不按期待结果挑颜色、轴、样本或误差呈现。生成式图像不得替代数据可视化或真实模型输出。
