# 章节自查与可选独立审阅

写完先核：事实/来源与条件、推理与解释、引用支持、术语/数值、可读性，最后改语言。审核者需看批准设计、实际证据和偏差，不只读作者的预期结论。

同一作者执行时如实称自查。涉及核心主张、复杂推导或较大改稿，独立审阅可能有帮助；先说明任务、输入/输出、范围及理由，按已有授权决定，不强制每节派 agent、不规定某产品的 agent 类型。

审阅输出包含具体位置、问题、依据、最强替代解释和建议；不得把建议自动写成研究事实。主 agent 核实后串行整合，避免并发改同一累计文件。研究未决交 iterate；语言修改不得新增机制、统计显著性或效果数字。

最终报告分开说明自查、独立审阅、文件/编译/视觉检查以及未做事项。审阅独立不等于判断正确，仍需逐项核证据。
