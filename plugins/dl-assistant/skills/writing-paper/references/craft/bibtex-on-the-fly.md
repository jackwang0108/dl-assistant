# 引用身份与论断支持关系

写作时同步登记真实引用，不设数量目标，不要求 core 文献固定篇数。core/supporting 可作组织标签，不能决定是否核查具体论断。

## 每条引用核两件事

1. **身份**：实际标题、完整作者、年份、版本、发表状态与稳定标识（DOI/arXiv/官方 URL）。区分预印本、正式发表版本、修订和更正；使用可核实的正式 BibTeX 或按真实元数据整理，不优先把所有文献写成 arXiv misc。
2. **支持关系**：这句话描述了该工作的什么，原文哪个节/图/表/公式支持，适用条件是什么。背景引用可只支持背景；不能用元数据/标题相近证明具体机制、性能数字、数据协议或未解决问题。

使用可用的 paper-search v2 / tex-mcp v2 / pdf-mcp 或官方材料。tex_open 固定原文版本；tex_references 保存该版 cite key、书目和引用位置，tex_reference_lookups 只生成待核输入，不自动认证外部身份。paper-search 用 resolve_papers/get_papers 核身份及字段出处，export_records 导出已取得的书目信息；缺失单列，不自动编造，BibTeX 导出不证明原文支持当前论点。接口按当前工具说明。实际无法取得原文时标未核实，不编造细节，也不假装已经全文读过。关键论断受影响时先缩为有依据的表述或保留工作占位，不等用户收尾才发现。

## references.json

每条或每个使用位置记录 cite_key、稳定标识、版本、身份来源、section（可为列表）、具体 claim、支持类型（直接/背景/比较/反对）、原文位置、核查状态与未决。相同文献在不同章节承担不同论断时分开记录 uses；不能只核一处后默认所有句子可用。

脚本核 cite↔bib 和登记位置，只能发现部分格式错误；不认证原文支持。无 bib 却已有正文引用是错误；缺登记应显示未完成，不能全跳过后称检查通过。

## BibTeX 与改稿

agent 主动整理可核实元数据、去重、保护专有名词大小写，并按实际样式编译检查。不同版本不机械合并；不改已有 cite_key 造成无关变更。缺失字段用未决说明，不能补假页码/会议名。具体条目格式与引用命令须结合实际模板/宏包和编译结果，不能把某命令直接等同于数字或作者年份制。

没有与论断相关的来源就不凑引用。相关研究分类应公平覆盖支持和反对证据，不把分类终点预设为本文必然优越。
