# 按表达目的设计图表

每个资产登记 id、class（schematic/dataviz）、subtype、要回答的问题、对应主张、来源、所在章节、必要程度、可编辑源/生成脚本、输出、版本和实际状态。id 保持稳定，不按图号变化重建；正文用 label/ref。

- 示意图解释真实对象或明确标注的概念；数据图/表呈现实际测量；真实输入、标签和预测分别注明来源。混合图也要逐部分区分。
- 先问图是否比文字/表更清楚，再选布局和信息编码；不强制每篇首图、架构图或固定数量的图。
- 选用统一而可区分的颜色、线型、符号和术语；有用户偏好直接采用，没有则 agent 提出合适方案。重要设计可给预览，不强制每张都先搜参考/锁定色卡。
- 颜色表达类别、连续值和差值时采用相应编码，不只靠颜色传关键信息。最终尺寸下检查字号、线宽、图例、裁切和灰度可读性。
- 图/表是否在正文、移动或缩放，按论证依赖、投稿要求和可读性决定。不能因名称或 priority 标签永久不可移动；重要内容取舍请用户决定。

保存实际状态与来源；不预填已批准/已验证。修改数据、机制、标签含义或统计方法时执行变化影响检查。
