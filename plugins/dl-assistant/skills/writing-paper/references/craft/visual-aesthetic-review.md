# 核对实际 PDF 的显示与可读性

使用实际环境可用的渲染工具，不预设某 MCP 或特定 API。初次全文查看，局部修改查看受影响页，定稿前全文复查；确认 PDF 与本次源版本一致。

- 内容显示：图表/公式完整，正文与 caption 不裁切，样本和标记没有误位；占位与缺失资产如实保留为未决。
- 引用：无未解析引用，编号对应正确对象；跳号是否异常按模板/附录实际编号方式判断，不机械要求全部连续。
- 可读性：最终物理尺寸下的字号、线宽、图例、公式、表头、单位和颜色能读清；缩放不能改变数据或遮住限制。
- 全文布局：浮动体距引用位置合理，无超宽、断表、空白页或大块不必要留白；章节/图表样式符合实际官方要求。
- 日志：核 undefined citation/reference、overfull、float too large 等，结合实际页判断，不把所有 warning 等同失败。

授权内可调整不改变含义的布局；改变内容优先级、删除证据、改 caption 结论或缩放到不可读时返回内容判断。模板不允许的间距/字体手段不得使用。

记录页码、症状、修改与复查结果。不能渲染时标未检查；用户最终审阅不替代 agent 自己先核能核的部分。
