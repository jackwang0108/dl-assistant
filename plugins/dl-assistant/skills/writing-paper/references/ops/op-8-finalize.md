# 整理可交付版本与后续事项

1. 核研究与关键自查、evidence-map、变化影响清单及所有重要未决。允许交明确标记的草稿；有影响核心结论的缺口不能称投稿就绪。
2. agent 完成授权范围内的图表终稿、BibTeX 身份/版本/格式修正、占位清理和交叉引用；只把需要用户判断或缺少素材的具体项目交用户，不固定等待 PPT 和手修文献。
3. 按实际官方要求核正文、附录、补充材料、匿名、声明与页数。需要内容取舍时提供保留依据和具体方案；已批准方案直接执行。任何图均按必要性和最终可读性安排，不按名称获得不可移动或不可缩放资格。
4. 运行文件检查、实际编译、日志核对和全文 PDF 渲染；在最后一次内容/版面变化后验证受影响部分。记录 PDF 与源文件版本/校验值、构建方式和实际检查范围。检查不完整不标全部通过。
5. 保存可恢复的正文、图表源、绘图/统计脚本、引用与数字出处、研究判断和实际工作记录。编译缓存可排除，不自动丢弃 _draft。未通过快照可保存，但和可交付版本明确区分。
6. 实际使用 Overleaf 且已授权同步时，按 latex-landing.md 比较、整合、有限重试并验证远端产物；否则本地交付，不强迫创建远端项目。不默认提交、tag、push 或投稿。
7. 更新 state 的实际状态、剩余任务、备份/同步和检查记录；保留历史。给用户简短汇报：本版主要贡献及证据范围、交付路径、通过的检查、无法验证项和下一步。
8. 按任务交review指定版本材料做独立预审，或交submission现有要求/材料做按需核对和人工提交准备；不必等论文完成才能查询要求。平台填写、上传和最终提交由用户完成。review维持独立审查范围，不能用写作内部判断代替审稿。
