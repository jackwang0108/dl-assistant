# 检查研究依据、全文一致性与呈现

1. 先查 evidence-map 与研究判断：核心主张、真实条件、反证/替代解释、未知和意义；正文不能超出证据。不能把结构说明和成稿一致当作二者都正确。
2. 按 [内容检查表](../craft/self-check.md) 核跨章术语/符号/数值、引用支持关系、附录与复现信息，优先检查核心结论和新改内容。独立审阅按需要和授权安排，不强制多 agent 或特定 agent 类型；自查如实标明是同一作者执行。
3. 运行 `python3 <skill目录>/scripts/run_checks.py <论文根> all`，保留实际报告。0 只说明所执行规则未发现硬错误；1 错误、2 用法错误、3 无法完成检查。WARN 结合语境处理；SKIP/UNCHECKED 列为范围或缺失，不能写成全通过。
4. 正则匹配不能判断科学诚信、投稿质量或文本作者身份。措辞建议不得删去真实局限；数字来源检查也不能代替统计代码/原数据/条件的语义核查。投稿要求仍需对照适用官方材料和实际 PDF。
5. 做简短读者检查：仅看标题、摘要、引言及关键图表说明，能否说明问题、实际新增、证据范围与意义？完整理解是否还需要合理的前置知识？不是测是否记住一个优势指标。
6. 有编译条件时核日志与实际 PDF，修改波及版式时重渲染；不能验证则标缺失。结合页限持续安排正文/附录，重要删除或主张变化交用户决定，日常排版和表达修正按授权完成。
7. 保存带唯一标识的 findings：位置、严重程度、依据、建议、处理状态及未决。核心问题返回 iterate；章节修改、引用/图表修正进入具体待办，不靠加强措辞“修复”研究。

交接前再执行 research-records.md 的最终自查。文件检查、编译、视觉审阅、研究判断分别报告，不合并成一个质量分数或“认证通过”。
