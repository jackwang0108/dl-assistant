# 与用户讨论证据并确定下一步

本文件说明怎样向用户讲清实验证据、仍成立的解释和下一步取舍，并记录双方实际确认的决定。

在[运行手册 Step 2](workflow.md#step-2-核证据并向用户解释)解释观察，在 [Step 3](workflow.md#step-3-形成并比较下一步建议)给出推荐，在 [Step 4](workflow.md#step-4-与用户确定下一步)核对实际决定。

## 1. 从读者需要知道的事实讲起

先给一段能单独读懂的概况。交代研究问题、原先要区分的解释、实际条件和关键观察、当前判断，以及为什么需要做下一项决定。再按用户兴趣展开相应图表、代码或文献。

- **用户熟悉任务时**，先给关键读数、可比条件与判断变化，说清还有哪条解释没有排除。需要时直接打开相应 run、图表或代码位置。
- **用户不熟悉时**，先用一个具体比较讲明白。例如少写回和换算子都可能让同一请求更快，可以先讲这两个因素为什么可能同时变化，再解释为什么要找能固定其中一个因素的对照。关键术语在首次用到时用一句话说明。
- **需要查证时**，说明这次要核哪条判断。拿到关键证据后，简要交代查了什么、它怎样改变建议、还缺什么。引用论文时给来源、实际读到的范围、它支持或挑战哪一步推理。检索范围与遗漏按实际记录。

说明实测、解释和待验证预测。已知事实用实际读数及条件说明，未决原因用有待检验的解释说明。有相反结果时，讲清它在哪些条件下出现。用户要跳到讨论下一步时，可先给建议，再按需要打开依据。

## 2. 给出首选，同时说明哪种结果会改变建议

主会话主动形成建议。给首选和少量实际可行的备选，分别说明能减少什么未知、基于什么、需要多少投入、不同结果会怎样改变决定。若当前没有值得运行的新对照，说明先核已有材料、收窄问题或暂停有什么理由。候选数量按决定需要。

用户可以直接提出想法或纠正前提，加入讨论后沿用同一套证据、适用范围和成本判断。对有分歧的地方先核能改变判断的证据。查文献时按[论文检索](../../paper-search/SKILL.md)核当前问题涉及的来源。需要深入复核现有实验时，按[证据复核与原因调查指引](autopsy-guide.md)查设计、实际条件和原始结果。

共同修改研究说明或取证方案时，每次说明改了什么、为什么改、哪些比较或假设因此变化。底稿保留已查依据。改动影响科学问题、指标、对照或投入时，标明需要确认的当前版本和范围。

## 3. 按上下文确认实际行动

| 用户怎样回应 | 怎样继续 |
| --- | --- |
| 对解释表示理解，或请继续查已有记录 | 沿明确范围继续讨论或复查。记录待查的证据和回报位置 |
| 给出新的证据或质疑某个前提 | 回查实际材料，说明支持、反对及未决的范围。根据结果更新建议 |
| 确认明确的下一步，例如先核算子日志 | 照已确认的动作推进。把已确认内容及停止点记入 `research-assessment.md` |
| 拟增加新实验、修改核心问题、投入资源或开始写作 | 讲清具体决定、依据、范围和代价，等用户确认。若只确认准备工作，记录准备任务及正式步骤的待决项 |
| 回复简短且所指范围不明 | 结合上一条明确提议判断。如果仍有会改变行动的歧义，就问清那项决定。已批准的其他工作可继续 |

上下文有明确请求时，「OK」可以确认该项行动。沉默或不明确的回应保留待确认。讨论同意、行动批准、命题获得证据和贡献确认分别按各自记录。按已获授权推进，无需逐段要求用户确认理解。

## 4. 示例 · 从配置收益谈到下一步取证

以下沿用[运行手册的虚构案例](workflow.md#示例--edge-vision)。

**Agent**　「同一设备、输入和计时口径下，原版 12.6 ms，组合 10.8 ms，快了 1.8 ms。我们原本想分清两个因素：一是写回的数据减少，二是运行时换了计算实现。现有轨迹显示两者一起变化，所以可以报告配置收益，原因还需要一项能把它们分开的对照。」

**用户**　「配置写了固定算子，为什么还要查？」

**Agent**　「配置说明我们要求用哪个实现。分派代码还会按输入条件选择路径，某些条件可能触发回退。要核的是这批输入实际选中的实现。我们可以先把四组配置和各自的运行日志、轨迹按 run ID 对起来，再看固定选项走到哪里。若已有一组实际算子相同、写回量不同的配对，就先复核已有读数。若只能确认源码有固定入口，再估一次最小的分派测量。」

**用户**　「先把已有的查一遍，查完告诉我。新的测量先等等。」

**Agent**　「好，我先查已有的四组轨迹、配置和分派代码。查完会给出实际算子、写回量和是否有可用配对。若还缺一次分派测量，我会说明它能解决什么及所需投入，届时再决定。」

在 `research-assessment.md` 记录这次确认：只复查已有数据、配置和代码；核出已有配对或确认现有材料不足后汇报；新测量及其预算待审。保留决定所依据的 OBS-02 与对应[调查记录](autopsy-template.md)。
