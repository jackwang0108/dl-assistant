# Calibration & Decision Matrix（评审校准 + 决策矩阵）

`writing-paper-review` 用，两半：① **reviewer 打分校准**（什么致命降大分、什么只扣分）② **AC decision matrix**（综合决策框架）。

> 和 `fairness-firewall.md` 是一对：防火墙是**下界**（什么不算拒稿理由），本文件是**上界**（什么真致命）+ AC 综合的决策层。

## 一、reviewer 打分校准

reviewer 知道用 venue 真实刻度打分，但容易失衡——过激（baseline 老一点就打拒）或过松（novelty 有硬伤还打勉强过线）。本节给刻度锚。

### 致命类（降大分，可构成拒稿理由）

过了 `fairness-firewall.md` 七条之后，**真致命**的才降大分：

- **novelty 被检索证伪** —— 动作 B 检索到已发表的高度相似工作（核心机制雷同）。**最致命**。
- **claim 过度声称、实验不支撑** —— 论文说的比实验证明的多（intro 许诺 experiment 没兑现、conclusion 比 data 走得远）。
- **方法根本性错误** —— 推导有错、实验设置不公平（故意给 baseline 劣势）、指标定义不标准导致结论不可信。
- **related work 严重脱节** —— 漏掉领域核心工作、引文严重过时（只引多年前），说明作者不掌握该领域现状。

### 扣分类（降小分，不致命）

见 `fairness-firewall.md` 过墙清单——缺一组消融、补实验、baseline 略老、写作小瑕疵。这些写进 weakness、建议作者改进，但**不该**因此打拒或强降分。

### ICLR2024 经验锚点（单会议参考，不硬套）

来源：有人爬 ICLR2024 OpenReview 几千份公开 review 统计得出——

| 问题类 | 降分幅度（ICLR2024）|
|---|---|
| 致命类（novelty / 过度声称 / related work 脱节）| 降 0.6-0.77 |
| 扣分类（补实验 / 缺 ablation）| 降 0.1-0.3 |

**⚠️ 单会议局限**：ICLR 用 OpenReview 全程公开才有这种统计；CVPR（封闭双盲）、期刊（不公开）没数据。ICLR2024 的降分幅度只代表 ICLR 评审生态，**不硬套**别的 venue（不同会议录用机制、口味、年份不同）。当「ICLR 经验锚点」参考，通用校准以本节致命/扣分两分类 + 各 venue 准则为准。

### 打分自洽（硬约束）

**给低分必须在 weakness 里有对应的硬伤**——低分无依据 = 评审不合格（ACL/EMNLP 准则）。致命类降大分要在 weakness 里能指出具体哪条；扣分类降小分不能堆成拒。

### 刻度锚点（防中庸塌缩——校准不是把分都往中段赶）

防火墙 + 打分自洽约束的是「别拿小瑕疵压分」，**不是**「没硬伤就给中段安全分」。全堆 borderline 的评审没有信息量。每个分段对应论文长什么样（按 venue 刻度映射，以 ICLR 1-10 为例）：

| 分段 | 论文长什么样 |
|---|---|
| 顶段（ICLR 8-10）| 贡献清晰且重要、实验充分、写作完整；瑕不掩瑜，明确该录 |
| 中段偏上（ICLR 6-7）| 贡献真实但平淡，或实验有小缺口；可录可拒，rebuttal 能定生死 |
| 中段偏下（ICLR 3-5）| 有明显短板（baseline 弱 / 分析缺失 / 贡献增量小）；默认偏拒，除非 rebuttal 翻盘 |
| 底段（ICLR 1-2）| 致命硬伤或严重不完整；明确该拒 |

**完成度规则**：半成品（实验残缺、章节未完成、图表占位）不是「内容之外的瑕疵」——presentation 与 contribution 子维度必须先垮，overall 跟着落到底段或中段偏下，**不许停在中段**。

### 打分程序（硬约束）

1. **子维度先行**：先按 venue 表单逐项打子维度分，每项对上方锚点给一句话依据。
2. **对比定位发问**：打 overall 前先回答「这篇相对该 venue 典型录用论文和典型拒稿论文，更像哪一边？」——答案写进报告。
3. **overall 由子维度 + 定位发问 + 锚点推出**——不许直接拍 overall；发现了硬伤就必须体现在分数上，不许弱点写一堆、分数全给中段。

## 二、AC decision matrix

AC prompt 现在只说"按 venue 真实录用机制综合"，没框架。本节给结构化决策表——AC 不是简单平均分数，而是**先核查、再权衡、再裁**。

### AC 的三个动作（顺序）

1. **核查 reviewer 意见是否成立**（对照 PDF 自己翻）：
   - reviewer 指出的问题论文里真有吗？有没有误读原文（尤其 borderline）？
   - 有误读 → **先纠正误读**，不按误读的分数进综合。
2. **分歧时判断信谁**（结合原文 + 必要时自己 paper-search 检索交叉核实）：
   - 分歧源于"误读 vs 准确" → 信准确的一方。
   - 分歧源于"口味差异"（一个偏理论严苛、一个偏应用价值）→ 两者都成立，看 fatal flaw 是否被任何一方坐实。
3. **致命硬伤检验**：有没有过 `fairness-firewall.md` 七条、又确属致命类（calibration 一节）且未被作者回应的硬伤？

### 决策表

| 情形 | 倾向 |
|---|---|
| 有真致命硬伤（novelty 证伪 / 过度声称 / 方法根本错误）且未被回应 | 偏 **reject**（期刊→Major Revision 或 Reject）|
| 魔鬼代言人指控经裁决成立（过墙 + 原文/检索支持）| 按致命硬伤对待（同上两行）|
| 无致命硬伤、reviewer 分歧小、多 borderline | 偏 **accept**（鼓励新颖冒险工作，CVPR/ICLR 准则）|
| 分歧大（同时有 strong reject + strong accept）| **自己翻原文裁**，不只看数；找出分歧根源再定 |
| 致命硬伤可补（补实验/补分析能解决）| 期刊→**Major Revision**；会议→borderline 偏拒（单轮改不了）|
| reviewer 普遍误读（同一处都理解错）| 先纠正误读，可能整体翻盘——不按原分数综合 |
| reviewer 评分挤在同一分段（如全 borderline）| **不许和稀泥**——meta-review 显式回答「为什么这篇不是明显的 accept 或明显的 reject」，给明确倾向 |

### AC 准则（写进 AC 人设）

- **不被"该有多少接受率"约束**（CVPR 准则）——基于论文本身的贡献与价值定，不看分数曲线。
- **borderline 时为新颖冒险工作说话**——鼓励大胆概念（CVPR/ICLR 准则），哪怕没在很多数据集验证。
- **裁决魔鬼代言人指控**——逐条对照原文 + 防火墙；成立的进致命类，不成立的记「已排除指控」（每条一句理由）写进 meta-review——这份清单是作者的 rebuttal 防线预演，不许省略。
- **期刊要给可逐条回应的清单**——major/minor points 编号，handoff 给 writing-paper-response。
