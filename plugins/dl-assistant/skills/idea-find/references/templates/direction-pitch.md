# 早期研究构想

一个候选一个文件，标题用具体问题而不是领域标签。不固定数量、行数或必须填满的字段。可以先发现问题再提出假设；尚未明确的写待澄清，agent主动推进，不靠用户提供全部创意。

```markdown
# {当前研究问题}
- 来源与日期：用户/agent/共同形成；实际素材位置。
- 具体观察或限制：事实、作者声明、猜测分别标明。
- 想知道什么：对象、关键概念、范围与所求答案。
- 当前解释或方法假设：为什么可能成立，前提与推导缺口。
- 替代解释与预测：什么观察能区分它们，未知之处。
- 如果成立新增什么：相对已有工作的认识/能力/决策意义。
- 哪些结果意义有限：不能只因测过新设置就算贡献。
- 下一步：先补什么文献、推理或观察，成本与依据。
- 当前建议及理由：继续讨论/取证/修改/暂缓/停止。
- 自查引用：当前candidate记录、输入版本、待修正项及其行动影响。
```

依据可以尚不充分，但不能把联想写成成立机制、把研究目标写成预测效果。没有现成benchmark或先例不自动排除；已有反证须核对条件。

保留用户的实际意见、agent建议与修订，不将“继续了解”写成兴趣确定或创新性确认。候选被替换/暂缓也留原因，没有必须只剩1–2个的要求。
