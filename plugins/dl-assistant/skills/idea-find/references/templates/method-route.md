# 本轮取证方案

路线可以是观察、测量、训练、干预或理论检查，不默认需要新网络或分析先行。多个方案按能回答的问题和成本比较，不固定数量或必须互斥。

```markdown
# {下一轮要回答的问题}
- 关联：当前Q/H编号、来源与版本，是否已有本项目数据。
- 开始前的认识：支持/反对依据、关键未知及替代解释。
- 本轮目标：减少什么不确定性，取得何种证据后改变哪个判断。
- 类型：探索/确认，若复用探索数据说明限制与后续独立检查。
- 实现或观察设计：输入输出、必要步骤/公式、变量、对照和适用条件。
- 可区分预测：不同解释下的可能观察，哪些结果仍无法区分。
- 测量与分析：样本单位、来源与划分、读数、误差、统计、原文依据。
- 结果解释：支持/反对/不足/不可区分/执行不可信分别意味着什么。
- 判断界限：依据、未知及先估计后确认的部分；不是预期增益承诺。
- 启动条件与成本：已知、估计及未知；资源、时间、数据与实现入口。
- 替代取证方案：能否用更便宜办法回答，为什么推荐当前方案。
- 研究价值：当前问题成立后新增什么，意义有限的结果及问题变更后的重评。
- 核查与未解决问题：具体依据、处置与是否阻塞。
- 批准范围：用户实际确认内容，未批准的后续设想另列。
```

证据缺口是研究的一部分，不以无先例降级。不存在可解释设计时先补推理，不能用“高风险高回报”包装。不要把所有检查项预填通过或填写没有来源的效应数字。

实现细节定到本轮需要的程度；最终仓库和精确入口待选型/环境准备绑定。关键科学设计不能甩给execution；后续有条件的研究分支可以说明，但不假设必然成功并设计整篇论文。
