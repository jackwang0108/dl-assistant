# 原文证据笔记

每篇/版本记录实际读取范围与来源，可按需补读，不因笔记存在就认为当前问题所需证据已齐。源码、PDF或网页都可用，不强求下载所有论文后再思考。

```markdown
# {论文标题}
- 身份与版本：arXiv/DOI/URL、实际版本、获取时间和文件位置。
- 阅读范围：已读章节/图表/证明/附录；没读到的明确列出。
- 作者主要声明：具体命题与条件，实际原文位置。
- 已核查依据：设置或假设、结果或推导、误差与外推范围。
- 机制解释：作者解释、我们推断、证据尚不足之处分开。
- 对当前假设的关系：支持哪一步、反对什么、可比条件和未知。
- 可以产生的新问题/替代解释：推理及所需证据，不等于作者未写就无人做。
- 后续检索与版本修订：真实发生时记录。
```

先用可用tex工具按节阅读，失败用PDF/网页，具体接口读对应工具skill。自行下载PDF核对有效性及版本，复杂图表看含图注的渲染。不能以关键词零命中替代阅读，也不以同词或相似图证明机制相同。

给主agent的摘要带关键来源位置与文件路径，需要时可回原文，不把逐条证据禁在摘要之外。误读纠正同步影响的判断和计划，不只在笔记末尾加备注后保留错误主张不变。
