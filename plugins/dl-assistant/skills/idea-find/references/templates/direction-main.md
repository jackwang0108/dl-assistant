# 当前研究问题与假设说明

研究问题决定想知道什么，假设提出可检验的解释/关系/解法，不提前写成论文结论。用于共同理解和价值讨论，后续交接草案从已确认版本生成。

```markdown
# {定义清楚的研究问题}
- 问题ID与版本：Q编号、日期、来源。
- 对象与范围：关键概念、当前边界、暂定与未知条件。
- 问题为何存在：具体观察、已有证据与原文位置。
- 已有工作解决了什么：最接近工作的真实内容与限制。
- 当前假设：H编号、命题、作用机制/推理、前提与缺口。
- 替代解释：各自预测，与当前假设重合和不同的地方。
- 证据状态：同条件支持/间接支持/尚无证据/相关反证/资料未取得。
- 成立后的意义：新增认识、能力或方法取舍，哪些结果不足以支持继续。
- 与已有工作的差异：具体对比、核查范围和创新性未决项。
- 下一步最重要的未知：证据需求，不等于实验已经批准。
- agent建议与用户意见：依据、未决定项、实际授权。
- 问题修订：原问题与当前问题，保留/失去的价值及重评结论。
- 自查引用：当前candidate记录、输入版本、待修正项及其行动影响。
```

问题可以独立、并行或相互关联，不强行拆成多方向；多个候选共享事实时说明联系，不因协议不同就拆成多篇论文。
