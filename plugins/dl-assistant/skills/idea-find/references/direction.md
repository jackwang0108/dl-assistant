# 主动发现问题与形成假设

## 1. 起点与共同理解

用户可给领域、论文、现象、方法联想、具体假设或旧研究记录。只询问会影响下一步的缺失信息：目标、兴趣、已有背景、已知资源和时间范围。会议未定、资源未实测、没有独特数据都可以保留未知，不为满足门槛编一个工作假设。

复用 paper-reading 的来源/已读范围/未决问题，literature-survey 的分类、文献和覆盖记录，以及 direction-tracking 的实际发现。按来源日期和阅读深度判断能复用什么，不一概视为过期，也不视为已验证创新。`worth_reading: false` 只表示当时阅读建议，不能当作质量低或课题不可做。

用户刚进入领域时，agent 先解释问题为什么重要、最接近工作做到了什么、候选假设新增什么。解释必要术语，按需回原文，让用户能够质疑具体依据，不只让其选标题或点头。

## 2. 主动提出候选

agent 负责检索、阅读和比较，可从以下信息提出不同类型问题，不固定菜单或数量：

- 多项结果之间的不一致，以及可能不同的条件或测量方式。
- 未解释现象、反常结果、模型能力边界或失败条件。
- 现有理论/方法依赖但未充分检查的前提。
- 数据、目标、表示与评测之间的错配，或重要任务尚缺的能力。
- 可迁移机制、用户经验与方法联想；需要检查迁移条件，不能仅凭同名术语。

文献既用于产生问题，也用于支持、反驳和重写问题；不能先生成后禁止调研改变议程。对作者 future work、可替换组件或两篇论文的交集，不自动当作新贡献。

候选数量由实质差异和讨论成本决定，避免多个名称表达同一想法。用户没有原始创意时主动提出；用户有想法时先准确理解并一起推理，不强制先拆成多个方向或保护其不受证据质疑。

使用 [问题构想记录](templates/direction-pitch.md)，早期缺项写待澄清，不为凑齐五行、命名 baseline 或预设主表填无依据数字。

## 3. 推理与文献交替

首轮查询从研究对象、现象或机制出发。已有构想时，另查解决同一问题的最接近方法、不同术语下的同类工作，以及可能削弱假设的结果。只有宽泛方向时，可先用检索结果收窄问题；候选成形或发生实质变化后，再按具体命题补查。

对每个有潜在意义的构想，检查：

1. 具体观察/限制及真实出 处，哪些还只是猜测。
2. 现有解释与最接近工作，条件与未解决之处。
3. 当前机制或解法假设，前提与逐步推理，缺口在哪里。
4. 替代解释及可区分预测，什么观察支持哪一种。
5. 假设成立后新增什么，意义有限的结果是什么。

重要定义、结论、数字到原文核实版本和位置；不能只从摘要判方法无效。来源选择随领域和检索问题，参考 literature-survey 的来源及记录原则，不强制近12个月+固定三平台。HF 只作补充；没有引用或未命中关键词不证明不重要或方向沉寂。

派子 agent 前按入口要求获得确认，任务可为独立解释生成、最近邻对比、条件核查或定向检索，不预设必须按固定三个通道派遣。不同解释分析时提供共同事实与问题，避免预填想要的结论。各写独立原始记录，主 agent 综合并核查冲突。

检索记录用 [来源记录模板](templates/direction-survey-channel.md)，文献和命题关系用 [证据索引](templates/direction-literature.md)，需要详细原文取证时用 [论文笔记](templates/method-note.md)。仅共享稳定标识或已核实互链才合并论文；标题相似保留待核查，版本与字段冲突不丢弃。

## 4. 当前研究问题与价值讨论

形成 [问题与假设说明](templates/direction-main.md)，区分：

- 研究主题/目标：想探索什么。
- 定义清楚的研究问题：对象、概念、范围、所求答案及其意义。
- 假设：具体解释或方法主张，前提、依据、未知与替代解释。
- 下一步证据需求：尚不等同于批准实验。

六项标准是问题具体、假设有内容、推理可检查、预测可区分、成立后有意义、取证合理。agent 说明满足到哪、需改进什么及自己的推荐，不汇总虚假分数，不按无先例自动排除。

不熟悉领域的用户不需要独自评价新颖性；agent 先解释对比依据、支持与反对理由。兴趣是参与决定的一部分，不证明贡献。用户要求补背景或再分析就继续，不把“没意见”记录成创新性成立。

[研究价值记录](templates/direction-importance.md) 与 [证据和启动条件](templates/direction-verify.md) 按需要更新，不各自强制派一个审稿人、不预测三年后热度或发表概率。审查分工：文献比较检查差异，技术分析检查推理，用户与主 agent 讨论价值，工程事实另由选型核实。

每次显著收窄重新比较原问题与当前问题，明确意义保留了什么、失去了什么。不能不断寻找没人测过的残余设置后自动立项。

## 5. 下一步决定

可以继续推理、补文献/观察、重新定义问题、设计取证、暂缓或停止。候选查新不通过不等于领域无价值；连续生成无进展时总结原因，与用户决定剩余预算，不固定两轮判结束。

用户认可当前价值后，若需要实验，进入 method.md；否则保存问题、理由、未知和下一步。确认下一步工作的“继续”不能充当假设或创新性的确认。
