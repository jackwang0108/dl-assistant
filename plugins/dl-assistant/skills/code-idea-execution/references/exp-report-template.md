# 实验 报告.md 模板（experiments/exp-XXX-<name>/报告.md）

每个实验一份，**人读**——你（用户）随时打开就能看明白这个实验。机读字段在 `meta.json` + `runs/seed-*/metrics.json`，台账全景在 `experiments/index.json`；本文件是单实验的「供用户阅读的实验摘要」，数字照抄机读文件，不另造字段。

**写法要求**：半页到一页；**只写现象，不写研究判断**（"所以该放弃 Y" 归 iterate）；失败、异常、意外观察如实写。每跑完一个实验就和 meta.json、台账一起增量写好，别攒到最后。

**读者视角组织**——打开报告的人按这个顺序问问题：结果是什么 → 为什么跑它 → 怎么跑的 → 细节在哪。模板就按这个顺序排。

---

```markdown
# exp-XXX-<name>：<一句话标题>

> **TL;DR**：<干了啥，一句话>｜<主指标> <本实验值> vs 锚点 <锚点值>（noise_floor <std>）｜**keep / discard**

## 为什么跑这个实验

## 怎么做的

## 结果与现象

## 产物
```

## 各节指引

### TL;DR（三行以内，结论先行）

读者只看这三行也该知道：这个实验干了什么、核心数字对比、判定结果。判定严格按 meta.json 预登记的 `decision_rule` 下，完成后仍用原先登记的规则判定。

- 浅（不合格）：「跑了模块 A 的实验，结果见下文。」——零信息，读者还是得翻全文。
- 深（合格）：「验 C2：加模块 A｜val cIoU 78.71 vs 锚点 77.49（+1.22，noise_floor 0.30，超判据线 +0.30）｜**keep**。」

### 为什么跑这个实验

两样：**此前哪些观察促成本实验**（基于前面什么观察才跑它——这是人读报告相对 meta.json 的核心增量，需要报告完整记录）+ **判据与对照运行**（验哪个子论点、预登记的 keep 线、和谁比）。

- 浅（不合格）：「验 C2，判据 cIoU 超锚点 +0.30。」——只重复了 meta.json 中的值，看不出这个实验为什么在此时出现。
- 深（合格）：「exp-002 发现 baseline 在高频区域误差集中（占 62%），C2 的动机正是补高频——本实验是最小验证：只加模块 A、其余冻结。预登记：val cIoU 超锚点（reduced baseline 77.49）≥ +2×noise_floor.std（0.30）才 keep，且新增代码 <100 行（复杂度权衡）。」
- 每个 Phase 的第一个实验没有前序观察，说明此前哪些观察促成本实验。可以写「plan 的 Phase-N 首发实验，目的是……」即可，不硬编。

### 怎么做的

**关键信息自包含**——读者不跳文件也该知道核心配置：相对 `reduced_setting`（或锚点配置）改了什么、核心超参、seed 及理由（固定减方差；delta 接近 noise_floor 才加）。指针（`configs/` 冻结副本、`scripts/` 启动脚本——完整命令在其中）只作备查，不放正文。

- 浅（不合格）：「配置见 configs/，命令见 scripts/。」——读者必须跳文件才知道你干了什么。
- 深（合格）：「锚点配置 + 模块 A（插入 stage3 后，dim 256）；lr 1e-4、10 epoch 不动；seed 42 固定（减方差）。完整 config 与命令见 configs/、scripts/。」

### 结果与现象

- **主数字**：本实验值 vs 锚点值 vs noise_floor（照抄 meta.json `results`），必要时一行次要指标；
- **判定**：keep / discard + 按预登记判据的一句话理由。**discard、指标倒退如实写**；
- **训练动态一句**：收敛是否正常（loss/metric 形状对照 `reproduction.json` 的 `baseline_curves`），异常时用一句话说明诊断结果；
- **意外观察**：实验中观察到的计划外现象（某个 split 异常涨、显存异常、某类样本全错……）——这往往可供下一版研究判断参考，没有就写「无」；
- **scale_risk**：meta.json 打了标的，这里把一句话理由带出来（CPE full-scale 优先验它）。

**诊断/分析类实验**：本节写分析结论（现象→数据→指向的根因），详版落 `analysis/report.md`，这里给摘要 + 指针。

### 产物

一行指针：「产物齐全（check-exp-artifacts.sh 过）：meta.json / configs/ / scripts/ / runs/seed-42/（train.log、eval.log、metrics.json）。」**只在缺项时展开写缺哪个、为什么**——机器已逐项查过，人读报告不重复审计清单。
