# 单实验报告

保存 `实验目录/报告.md`，结果出现、失败或暂停时更新，不攒到最后。报告自足，详细来源可链接，不能只贴一个指标。

```markdown
# {实验ID}：{问题}
> 执行状态、数据有效性、证据支持程度分别列出；未核查明确写出。

## 为什么做
原先的认识、依据、本轮未知和关联Q/H/C；探索还是预先检验。

## 实际怎么做
模型/数据/样本划分、对照、配置与代码版本、读数和分析；与计划的偏差。

## 观察与限制
真实结果、分母/单位、区间/误差及来源；运行失败与缺失项。
哪些解释被支持、受到反对、仍不足或无法区分；未经核查标暂定。

## 意外观察与解释建议
观察事实、可能解释及替代解释分开，标是否事后发现；不声称根因已证实。

## 来源与下一步
结果路径、设计副本、日志/退出状态、代码与配置、未完成任务。
下一步只作建议，不自动实施。
```

无指标改善也可以完成实验；有效阴性保留。执行失败不能填成负效果，文件检查通过不等于数据已有效。统计、实用意义及新颖性不能用keep/discard代替。

## 研究条件核对（与本轮用途有关时）

引用条件记录的路径和版本，写明目标与实际条件、必须保留项的代码/配置/数据位置及检查证据、未知/偏差、所查范围和不能外推的内容。记录下一次目标条件验证的触发点或不适用理由。按本 skill 职责分别说明静态调查、准备、阅读或实际运行，不能将尚待检查项写成已落实；条件或假设变化后重新核对。
