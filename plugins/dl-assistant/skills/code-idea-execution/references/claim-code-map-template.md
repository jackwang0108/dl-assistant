# 问题、假设、实验与实现对应记录

保存为 `03-claim-code-map.md`，用于用户实际代码审阅和后续追溯。纯测量/统计实验也有映射；工程前置任务可以只关联研究问题，不制造假设ID。

```markdown
# 本轮实现与测量映射
> 研究问题与计划版本、代码commit/diff位置。

## {Q/H/C编号或前置任务}
- 要回答什么：当前命题或未知，不预设结论。
- 对应实验与读数：来源、变量和实际定义。
- 实际代码：模块/函数、commit、真实行位置；数据/测量/统计代码也列出。
- 操作与机制：输入输出、对照、计算步骤、关键条件。
- 能区分与不能区分什么：识别限制、待检查前提。
- 实际diff与测试：关键改动、测试数据和结果、未覆盖范围。
- 用户审阅：实际审阅范围、答复、修订与未决项。
- 开跑前自查：pre_run记录路径及对应设计/代码版本；未解决项和是否影响当前运行。

## 顺序与依赖
实际前置任务、独立可并行项、需要结果后再讨论的项。
```

继承实现需核对当前commit与实验条件，不能因以前supported就永远免检。实质修改后更新映射并请用户重新审阅相关部分，不能只口头讲代码替代展示diff。
