## 模板使用说明

- **叙述关的底稿**：用户审的就是这份——讲不出清晰的「为啥能验证」= 没对上，回去改实现，不开跑。
- **前提假设必须诚实**：这是验收子 agent 和 iterate 判断"真测到了什么"的关键输入；写不出前提假设往往意味着验证逻辑没想清。
- **随实现演进更新**：实现改了（卡死回退、微观迭代调实现）地图同步改，保持 file:line 真实——release 抽发行版时按它找代码，假指针比没有还糟。
- **支撑实验回指**：和 meta.json 的 `claim_cids` 互相对得上（地图 → 实验、实验 → claim 双向可查）。
